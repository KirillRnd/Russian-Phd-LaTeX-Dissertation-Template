\section{Заключение}

\begin{frame}[t]
    \frametitle{Главный результат диссертации}
    \presentationtextsize
    Вычислительная схема, реализованная в ILTT Toolbox:

    \begin{enumerate}
        \item Для заданной даты старта по цепочке конечных формул выбирается точка оптимальной дальности на расслоении ИРТ-решений.
        \item По конечным формулам в точке оптимальной дальности вычисляются продолжительность компланарного перелёта между круговыми орбитами и начальные значения сопряжённых переменных ИРТ-траектории.
        \item По конечным формулам вычисляются управляющие параметры композиции \(R\)-преобразований с учётом коррекции витковой дальности.
        \item Начальное приближение численно уточняется в пространстве управляющих параметров до точного ИРТ-решения целевой задачи встречи.
        \item Полученное ИРТ-решение продолжается к оптимальному гиперболическому избытку с учётом ограничений РБ.
        \item ИРТ-решение с оптимальным гиперболическим избытком продолжается к ПСИ-постановке.
    \end{enumerate}

    \vfill
    \begin{lowerbar}
        Главный результат диссертации -- вычислительная схема, позволяющая через модельное многообразие, конечные формулы и \(R\)-преобразования перейти от расслоения ИРТ-решений к начальному приближению для прикладной баллистической задачи.
    \end{lowerbar}
\end{frame}

\begin{frame}
    \frametitle{Положения, выносимые на защиту}
    \small
    \begin{enumerate}
        \item Разработана методика исследования расслоения ИРТ-решений по числу витков и выделены точки оптимальной дальности как основной объект последующей аппроксимации.
        \item Получены конечные формулы, позволяющие по параметрам компланарного перелёта между круговыми орбитами выбрать точку оптимальной дальности и вычислить характеристики ИРТ-траектории.
        \item Разработаны линейные преобразования начальных значений сопряжённых переменных и применены для учёта эллиптичности и пространственной ориентации конечной орбиты при переходе к целевой задаче встречи.
        \item Построен алгоритм выбора начального приближения и использован для решения целевых задач встречи с последующим продолжением к ПСИ-постановке.
    \end{enumerate}
\end{frame}
