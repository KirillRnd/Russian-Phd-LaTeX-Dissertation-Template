\section{Введение}

\begin{frame}[t]
    \frametitle{Мотивация}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.50\textwidth}
            \presentationtextsize
            В межпланетном баллистическом проектировании для выбора окна старта используют графики типа \textbf{«ракушка» (porkchop plot)}

            \medskip
            На таких графиках сопоставляются:
            \begin{itemize}
                \item дата старта
                \item продолжительность перелёта
                \item расход рабочего тела
            \end{itemize}

            \medskip
            В работе рассматривается, как эта привычная баллистическая картина меняется для перелётов с непрерывной тягой
        \end{column}

            }
        \end{column}
    \end{columns}

    \vfill
    \begin{lowerbar}

    \end{lowerbar}

\begin{frame}[t]
    \frametitle{Актуальность}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.43\textwidth}
            \presentationtextsize
            Для перелётов с непрерывной тягой классическая «ракушка» расслаивается по числу витков траектории

            \medskip
            Одним и тем же значениям даты старта и продолжительности перелёта могут соответствовать траектории с разным числом витков

            \medskip
            Таким образом, расслоение связано с геометрией траекторий, а не с ветвлением по активным и пассивным участкам тяги
        \end{column}
        \begin{column}{0.53\textwidth}

            }
        \end{column}
    \end{columns}

    \begin{lowerbar}
        При выборе окна старта необходимо также выбрать семейство решений\\
        и согласованное с этим семейством начальное приближение
    \end{lowerbar}
\end{frame}

\begin{frame}[t]
    \frametitle{Проблематика}
    \presentationtextsize
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.46\textwidth}
            При анализе расслоения по числу витков необходимо отделить его от влияния дополнительных факторов. К таким факторам относятся:
            \begin{itemize}
                \item эллиптичность орбит
                \item пространственность манёвра
                \item величина тяги
                \item масса КА
            \end{itemize}
        \end{column}
        \begin{column}{0.53\textwidth}
            В классическом анализе движения КА с малой тягой у В.~Н.~Лебедева геометрия перелёта декомпозируется относительно круговой начальной орбиты. Рассматриваются три базовых случая:
            \begin{itemize}
                \item перелёт между компланарными круговыми орбитами
                \item перелёт между компланарной круговой и эллиптической орбитами
                \item перелёт между некомпланарными круговыми орбитами
            \end{itemize}
        \end{column}
    \end{columns}

    \vfill
    \begin{lowerbar}
        После геометрической декомпозиции остаются два внешних фактора:\\
        величина тяги и масса КА
    \end{lowerbar}
\end{frame}

\begin{frame}[t]
    \frametitle{Предмет исследования}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.50\textwidth}
            \presentationtextsize
            Для учёта величины тяги и изменения массы КА за счёт расхода рабочего тела задаётся модель двигателя малой тяги. Г.~Л.~Гродзовский выделяет две модельные постановки:
            \begin{itemize}
                \item ПСИ -- постоянная скорость истечения рабочего тела, при которой величина тяги является явным параметром задачи
                \item ИРТ -- идеально регулируемая тяга, при которой динамическая задача отделяется от параметрической
            \end{itemize}

            \medskip
            В работах В.~Г.~Петухова ИРТ-решение используется как начальное приближение для продолжения к ПСИ-постановке
        \end{column}
        \begin{column}{0.46\textwidth}
            \centering
            \includegraphics[width=\linewidth,height=0.46\textheight,keepaspectratio]{petukhov}

            \vspace{0.06cm}
            {\presentationtextsize
            ИРТ--ПСИ продолжение на примере миссии к астероиду 2000 WO10
            }
        \end{column}
    \end{columns}

    \vfill
    \begin{lowerbar}
        Предметом исследования является расслоение по числу витков\\
        в ИРТ-постановке с учётом геометрической декомпозиции задачи\\
        для построения согласованного начального приближения
    \end{lowerbar}
\end{frame}

\begin{frame}
    \frametitle{Цель и задачи}
    \presentationtextsize
    \textbf{Цель работы} -- разработать и апробировать численно-аналитический метод согласованного выбора продолжительности перелёта и ИРТ-траектории в качестве начального приближения с учётом расслоения на заданную дату старта.

    \medskip
    Для достижения цели решаются задачи:
    \begin{enumerate}
        \item разработать методику исследования расслоения ИРТ-решений через построение и аппроксимацию модельного многообразия задачи встречи;
        \item получить конечные формулы, связывающие параметры компланарного перелёта между круговыми орбитами с характеристиками ИРТ-траектории и начальными значениями сопряжённых переменных;
        \item разработать метод учёта эллиптичности и пространственной ориентации конечной орбиты при переходе от модельной ИРТ-траектории к целевой задаче встречи;
        \item построить алгоритм, который по дате старта и параметрам целевой задачи встречи выбирает продолжительность перелёта и модельную ИРТ-траекторию как начальное приближение.
    \end{enumerate}
\end{frame}

\begin{frame}[t]
    \frametitle{Модельная краевая задача}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.5\textwidth}
            \presentationcompactsize
            Функционал
            \begin{flushleft}
            \(\displaystyle J=\frac{1}{2}\int\limits_{t_0}^{t_f}\|\mathbf a(t)\|^2\,dt \to \min.\)
            \end{flushleft}
            \vspace{-0.18cm}
            Функция Гамильтона--Понтрягина
            \begin{flushleft}
            \(\displaystyle H=\mathbf p_r^{T}\mathbf v+
            \mathbf p_v^{T}\left(-\frac{\mathbf r}{r^3}+\mathbf a\right)
            -\frac{1}{2}\mathbf a^{T}\mathbf a.\)
            \end{flushleft}
            \vspace{-0.18cm}
            Оптимальное управление
            \begin{flushleft}
            \(\displaystyle \frac{\partial H}{\partial \mathbf a}=0
            \quad\Rightarrow\quad
            \mathbf a=\mathbf p_v.\)
            \end{flushleft}
            \vspace{-0.18cm}
            Расширенная система уравнений движения
            \begin{flushleft}
            \(\displaystyle
            \left\{
            \begin{aligned}
            \dot{\mathbf r} &= \mathbf v,\\
            \dot{\mathbf v} &= -\frac{\mathbf r}{r^3}+\mathbf p_v,\\
            \dot{\mathbf p}_r
            &= \frac{1}{r^3}\mathbf p_v
            -\frac{3}{r^5}(\mathbf r\cdot\mathbf p_v)\mathbf r,\\
            \dot{\mathbf p}_v &= -\mathbf p_r.
            \end{aligned}
            \right.
            \)
            \end{flushleft}
            \vspace{-0.18cm}
            Витковая дальность
            \begin{flushleft}
            \(\displaystyle \lambda=\frac{\varphi}{2\pi}.\)
            \end{flushleft}
        \end{column}
        \begin{column}{0.49\textwidth}
            {\centering
            \includegraphics[width=0.65\linewidth,keepaspectratio]{virtual_planet}
            \par}

            \vspace{-0.03cm}
            \presentationcompactsize

            \begin{flushleft}
            \(\displaystyle \mathbf r_0=(1,0,0)^{T},\)\\
            \(\displaystyle \mathbf v_0=(0,1,0)^{T},\)\\
            \(\displaystyle \mathbf r_f=\kappa(\cos 2\pi\lambda,\sin 2\pi\lambda,0)^{T},\)\\

\begin{frame}[t]
    \frametitle{Модельное многообразие}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.58\textwidth}
            \centering
            \includegraphics[height=0.7\textheight]{continuation_paths}
        \end{column}
        \begin{column}{0.38\textwidth}
            \presentationcompactsize
            Параметры многообразия
            \begin{flushleft}
            \(\displaystyle \boldsymbol\xi=(\lambda,\kappa).\)
            \end{flushleft}
            \vspace{-0.18cm}
            Отображение параметров в решение КЗ
            \begin{flushleft}
            \(\displaystyle M(\boldsymbol\xi):\boldsymbol\xi\mapsto
            \bigl(\mathbf z_0,T,\Psi,J\bigr)(\boldsymbol\xi).\)
            \end{flushleft}
            \begin{itemize}
                \item Модельное многообразие понимается как образ отображения, построенного на одной регулярной ветви решений.
                \item Базовое решение используется как исходная точка для продолжения по сетке параметров.
                \item Соседние решения дают начальное приближение для следующей краевой задачи.
                \item Вычислительные барьеры отделяют границы устойчивого локального продолжения.
            \end{itemize}
        \end{column}
    \end{columns}
    \begin{newresult}
        Предложен метод построения модельного многообразия энергетически оптимальных решений задачи встречи, параметризованного \((\lambda,\kappa)\).
    \end{newresult}
\end{frame}

\begin{frame}
    \frametitle{Метод символьной регрессии}
    \presentationtextsize
    \[
    M(\lambda,\kappa)
    \longrightarrow
    \widehat T,\ \widehat\Psi,\ \widehat J,\ \widehat{\mathbf z}_0.
    \]
    \begin{itemize}
        \item Механическая структура задаётся ИРТ-КЗ, расширенной системой и параметрами \((\lambda,\kappa)\).
        \item Численные решения анализируются в параметрических представлениях, согласованных с этой структурой.
        \item Для регулярных зависимостей строятся непосредственные аппроксимации; для более сложных -- иерархические коэффициент-функции.
        \item Символьная регрессия применяется как инструмент компактной записи интерпретируемых формул.
        \item Качество формул проверяется метриками ошибок и краевыми невязками после интегрирования расширенной системы.
    \end{itemize}
\end{frame}

\begin{frame}[t]
    \frametitle{КЛО и точки оптимальной дальности}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.58\textwidth}
            \centering
            \includegraphics[height=0.6\textheight]{Isolines}
        \end{column}
        \begin{column}{0.41\textwidth}
            \presentationtextsize
            \[
            \Phi=\mathrm{const}
            \quad\cap\quad
            \mathrm{КЛО}
            \quad\Rightarrow\quad
            \lambda^\star.
            \]
            \[
            \varphi=\Phi+\frac{T}{\kappa^{3/2}}.
            \]
            \begin{itemize}
                \item Дата старта задаёт начальную синодическую фазу.
                \item КЛО связывает структуру ветвей с выбором \(\lambda^\star\).
                \item Изолиния фиксированной фазы пересекает КЛО в точке оптимальной дальности.
                \item Точка оптимальной дальности задаёт витковую дальность выбранной ветви.
            \end{itemize}
        \end{column}
    \end{columns}
    \begin{newresult}
        КЛО и точки оптимальной дальности связывают начальную синодическую фазу с выбором ветви решения.
    \end{newresult}
\end{frame}
