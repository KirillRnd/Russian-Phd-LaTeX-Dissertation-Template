\section{Введение}

\begin{frame}
    \frametitle{Актуальность}
    \small
    \begin{itemize}
        \item Межпланетные перелёты с электрореактивной тягой формируются в результате длительного управляемого движения.
        \item На ранних этапах баллистического проектирования требуется многократно оценивать даты старта, продолжительность перелёта, расход рабочего тела и параметры управления.
        \item Непрямой метод требует начального вектора сопряжённых переменных, чувствительного к выбранной ветви решения.
    \end{itemize}

    \vspace{0.2cm}
    \begin{block}{Проектная цепочка}
        \scriptsize
        Дата старта и целевая орбита определяют выбор ветви решения; затем оцениваются продолжительность перелёта, энергетический критерий и начальный вектор, после чего выполняется численное уточнение краевой задачи.
    \end{block}
\end{frame}

\begin{frame}
    \frametitle{Цель и задачи}
    \small
    \textbf{Цель:} разработать и апробировать численно-аналитический метод построения начальных приближений для энергетически оптимальных межпланетных перелётов с непрерывной тягой на основе аппроксимации модельного многообразия решений задачи встречи.

    \medskip
    Для достижения цели решаются задачи:
    \begin{enumerate}
        \item построить регулярное модельное многообразие решений задачи встречи;
        \item получить конечные формулы для характеристик экстремалей и начального вектора сопряжённых переменных;
        \item разработать линейные преобразования начальных значений сопряжённых переменных для перехода к эллиптической и пространственной конечной орбите;
        \item построить алгоритм выбора начального вектора и проверить его на прикладных классах перелётов.
    \end{enumerate}
\end{frame}

\begin{frame}[t]
    \frametitle{Идеально регулируемая тяга (ИРТ) как модельная краевая задача}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.48\textwidth}
            \tiny
            \[
            \left\{
            \begin{aligned}
            \dot{\mathbf r} &= \mathbf v,\\
            \dot{\mathbf v} &= -\frac{\mathbf r}{r^3}+\mathbf a,
            \end{aligned}
            \right.
            \]
            \[
            \begin{aligned}
            \mathbf r_0&=(1,0,0)^{T},\\
            \mathbf v_0&=(0,1,0)^{T},\\
            \mathbf r_f&=\kappa(\cos\varphi,\sin\varphi,0)^{T},\\
            \mathbf v_f&=\kappa^{-1/2}(-\sin\varphi,\cos\varphi,0)^{T}.
            \end{aligned}
            \]
            \[
            J=\frac{1}{2}\int\limits_{t_0}^{t_f}\|\mathbf a(t)\|^2\,dt \to \min.
            \]
            \[
            \mathbf z_0=\left(\mathbf p_{r0},\mathbf p_{v0}\right),
            \qquad
            \mathbf a=\mathbf p_v.
            \]
            \begin{itemize}
                \item \(\mathbf r_0,\mathbf v_0\) фиксированы.
                \item \(\mathbf r_f,\mathbf v_f\) задаются через \(\varphi\) и \(\kappa\).
                \item В ИРТ \(\mathbf a\) -- реактивное ускорение; \(\mathbf a=\mathbf p_v\).
                \item ИРТ используется как регулярная модельная краевая задача для построения начального приближения.
            \end{itemize}
        \end{column}

\begin{frame}[t]
    \frametitle{Модельное многообразие и дискретное продолжение}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.58\textwidth}
            \centering
            \includegraphics[height=0.48\textheight]{continuation_paths}
        \end{column}
        \begin{column}{0.38\textwidth}
            \tiny
            \[
            \boldsymbol\xi=(\lambda,\kappa)
            \quad
            \text{для плоской круговой модели.}
            \]
            \[
            \mathbf z(\boldsymbol\xi)\in\mathbb R^6,
            \qquad
            \mathbf c(\boldsymbol\xi)\in\mathbb R^n.
            \]
            \[
            M:D_{\mathrm{reg}}\to\mathbb R^{6+n},
            \qquad
            M(\boldsymbol\xi)=
            \bigl(\mathbf z(\boldsymbol\xi),\mathbf c(\boldsymbol\xi)\bigr).
            \]
            \begin{itemize}
                \item Модельное многообразие понимается как образ отображения, построенного на одной регулярной ветви решений.
                \item Вектор \(\mathbf c(\boldsymbol\xi)\) содержит характеристики построенной экстремали.
                \item Базовое решение используется как исходная точка для продолжения по сетке параметров.
                \item Соседние решения дают начальный вектор для следующей краевой задачи.
                \item Вычислительные барьеры отделяют границы устойчивого локального продолжения.
            \end{itemize}
        \end{column}
    \end{columns}
    \begin{newresult}
        Разработана методика построения регулярного модельного многообразия методом дискретного продолжения.
    \end{newresult}
\end{frame}

\begin{frame}
    \frametitle{От многообразия к конечным формулам}
    \small
    \[
    M(\boldsymbol\xi)
    =
    \bigl(\mathbf z(\boldsymbol\xi),\mathbf c(\boldsymbol\xi)\bigr),
    \qquad
    \mathbf c=(\Phi,\lambda,T,J).
    \]
    \[
    M(\boldsymbol\xi)
    \longrightarrow
    \widehat T,\ \widehat\Psi,\ \widehat J,\ \widehat{\mathbf z}_0.
    \]
    \begin{itemize}
        \item Численные решения анализируются в выбранных параметрических представлениях.
        \item Для регулярных зависимостей строятся непосредственные аппроксимации.
        \item Для более сложных зависимостей используется иерархический подход с коэффициент-функциями.
        \item Символьная регрессия используется как инструмент получения конечных формул.
        \item Качество формул проверяется метриками ошибок и краевыми невязками после интегрирования расширенной системы.
    \end{itemize}
    \begin{newresult}
        Задана методика получения интерпретируемых конечных формул для характеристик экстремалей и начальных значений сопряжённых переменных.
    \end{newresult}
\end{frame}

\begin{frame}[t]
    \frametitle{КЛО и точки оптимальной дальности}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.58\textwidth}
            \centering
            \includegraphics[height=0.48\textheight]{Isolines}
        \end{column}
        \begin{column}{0.38\textwidth}
            \scriptsize
            \[
            \Phi=\mathrm{const}
            \quad\cap\quad
            \mathrm{КЛО}
            \quad\Rightarrow\quad
            \lambda^\star.
            \]
            \[
            \varphi=\Phi+\frac{T}{\kappa^{3/2}}.
            \]
            \begin{itemize}
                \item Дата старта задаёт начальную синодическую фазу.
                \item КЛО (кривая локальных оптимумов) строится как отдельная ветвь решений.
                \item Пересечения КЛО с изолиниями фиксированной начальной синодической фазы образуют точки оптимальной дальности.
                \item Точка оптимальной дальности задаёт \(\lambda^\star\).
            \end{itemize}
        \end{column}
    \end{columns}
    \begin{newresult}
        Выделены КЛО и точки оптимальной дальности как механизм выбора ветви по фиксированной начальной синодической фазе.
    \end{newresult}
\end{frame}
