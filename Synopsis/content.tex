\synopsisheading{Актуальность темы исследования}{actuality}
Электрореактивные двигательные установки (ЭРДУ) расширяют множество доступных баллистических схем межпланетных миссий, особенно для малых космических аппаратов (КА): высокий удельный импульс позволяет получить большой располагаемый запас характеристической скорости при ограниченной массе рабочего тела. Однако малая тяга требует длительного управляемого движения, а~характеристики перелёта существенно зависят от~даты старта, продолжительности перелёта, целевой орбиты, параметров КА и~двигателя.

На~ранних этапах баллистического проектирования необходимо анализировать большие массивы траекторий, соответствующих различным наборам этих параметров. Непосредственное численное решение задачи оптимального управления для каждого набора становится существенным вычислительным ограничением. Известные конечные формулы и~асимптотические решения сокращают объём таких расчётов лишь в~специальных случаях: для близких орбит, усреднённых многовитковых перелётов или постановок с~дополнительными упрощающими предположениями. Для межпланетных перелётов с~малым числом витков, существенным изменением радиуса орбиты и~непериодическим управлением такие приближения недостаточны.

Номограммы, связывающие дату старта, продолжительность перелёта и~его энергетические характеристики, служат одним из~основных средств предварительного выбора траектории. При непрерывной тяге изолинии энергетических характеристик на~номограмме могут расслаиваться на~области, соответствующие разному числу витков. Поэтому выбор окна старта неотделим от~выбора семейства траекторий. Для последующего уточнения непрямым методом требуются начальные значения сопряжённых переменных, согласованные с~выбранным семейством; произвольное начальное приближение может привести к~сходимости численного метода к~другому локальному решению либо к~отсутствию сходимости.

В~этих условиях актуально построение промежуточного численно-аналитического представления, которое связывает результаты массового расчёта энергетически оптимальных траекторий с~компактными конечными формулами. Оно должно быть пригодным для интерпретации и~быстрого построения начального приближения, но~при этом сохранять структуру оптимальных решений, выбор семейства траекторий и~начальные значения сопряжённых переменных. В~настоящей работе таким представлением служит модельное многообразие решений задачи встречи.

\synopsisheading{Степень разработанности темы исследования}{elaboration}
Задачи проектирования межпланетных перелётов с~непрерывной тягой развиваются на~стыке механики космического полёта, теории оптимального управления и~численных методов. С~работами школы Д.Е.~Охоцимского связана отечественная традиция постановки и~численного исследования задач космической динамики. В~работах Т.М.~Энеева и~соавторов развивались методы проектирования траекторий с~малой тягой и~графические средства предварительного баллистического анализа. Эта научная линия сформировала методическую основу для исследования семейств межпланетных траекторий.

Теоретической основой непрямой оптимизации служит принцип максимума Л.С.~Понтрягина. Его применение к~перелётам с~непрерывной тягой приводит к~расширенной системе фазовых и~сопряжённых переменных и~двухточечной краевой задаче. В~работах В.Г.~Петухова развиты методы оптимизации многовитковых межорбитальных и~межпланетных перелётов, в~том числе с~продолжением по~параметрам граничных условий. Продолжение позволяет прослеживать отдельную ветвь от~известного решения, но~требует последовательно решать краевые задачи и~само по~себе не~даёт конечных формул для построения начального приближения.

Известные аналитические и~усреднённые методы дают конечные зависимости для близких орбит, усреднённых многовитковых перелётов и~ряда других специальных режимов. Для межпланетных перелётов с~малым числом витков, существенным изменением радиуса орбиты и~непериодическим управлением универсальные компактные формулы не~получены. В~то~же время более общие численные методы не~устраняют многорешённость краевой задачи и~её чувствительность к~начальному приближению.

Современные методы аппроксимации, в~том числе символьная регрессия, позволяют извлекать конечные формулы из~массивов численных данных. Однако непосредственная аппроксимация разнородного массива может смешивать различные ветви и~не гарантирует корректного поведения полученных выражений. Поэтому недостаточно разработаны методы построения регулярного параметрического представления множества энергетически оптимальных решений, которые одновременно сохраняют структуру решений, выбор семейства траекторий и~начальные значения сопряжённых переменных. В~настоящей работе такое представление строится в~виде модельного многообразия, а~символьная регрессия используется после механического анализа, выбора параметризации и~нормировки переменных.

\synopsisheading{Цель работы}{aim}
Цель работы --- разработать и~апробировать численно-аналитический метод формирования начального приближения для энергетически оптимального межпланетного перелёта с~идеально регулируемой тягой. Метод должен обеспечивать выбор заданного семейства траекторий в~расслоении по~числу витков на~основе модельного многообразия решений задачи встречи.

Для достижения поставленной цели необходимо решить следующие \textbf{задачи}:
\begin{enumerate}[beginpenalty=10000]
    \item разработать методику построения, исследования и~аппроксимации модельного многообразия решений задачи встречи с~идеально регулируемой тягой, позволяющую описывать расслоение по~числу витков;
    \item исследовать модельное многообразие решений в~плоской круговой модели движения небесных тел, выделить точки оптимальной дальности и~построить конечные формулы, связывающие параметры компланарного перелёта между круговыми орбитами с~характеристиками траектории и~начальными значениями сопряжённых переменных;
    \item разработать линейные преобразования начальных значений сопряжённых переменных, позволяющие учитывать изменение начального фазового вектора, эллиптичность и~пространственную ориентацию конечной орбиты при переходе от~плоской круговой модельной постановки к~целевой задаче встречи;
    \item построить и~апробировать алгоритм формирования начального приближения, согласованного с~выбранным семейством траекторий, по~заданной дате старта и~параметрам целевой задачи встречи, в~том числе для перелётов Земля--Марс и~Земля--Венера, постановок с~дополнительным импульсом скорости в~начальный момент времени и~последующего продолжения к~постановке с~постоянной скоростью истечения.
\end{enumerate}

\synopsisheading{Объект и предмет исследования}{objectsubject}
Объектом исследования являются семейства энергетически оптимальных решений задач встречи с~идеально регулируемой непрерывной тягой, расслаивающиеся по~числу витков. Предмет исследования --- численно-аналитические методы построения и~аппроксимации модельного многообразия для выбора семейства траекторий и~формирования начального приближения.

\synopsisheading{Положения, выносимые на защиту}{defpositions}
На~защиту выносятся следующие положения:
\begin{enumerate}[beginpenalty=10000]
    \item предложена методика исследования расслоения решений задачи встречи с~идеально регулируемой тягой по~числу витков. Методика основана на~построении модельного многообразия решений двухточечной краевой задачи с~помощью дискретного продолжения по~параметрической сетке и~последующей аппроксимации его характеристик. В~рамках методики выделены точки оптимальной дальности, используемые как основной объект аппроксимации и~выбора начального приближения;

    \item для плоской круговой модели движения небесных тел предложены конечные формулы, полученные с~использованием символьной регрессии и~позволяющие по~параметрам компланарного перелёта между круговыми орбитами выбирать точку оптимальной дальности и~вычислять характеристики ИРТ-траектории. Предложенные формулы связывают параметры модельной задачи с~продолжительностью перелёта, значением квадратичного функционала, начальной синодической фазой и~начальными значениями сопряжённых переменных;

    \item разработан аппарат линейных преобразований начальных значений сопряжённых переменных, используемый при переходе от~плоской круговой модельной постановки к~целевой задаче встречи. Эти преобразования позволяют учитывать изменение начального фазового вектора, эллиптичность и~пространственную ориентацию конечной орбиты. Для управляющих параметров этих преобразований предложены конечные формулы, а~также построена линейная коррекция витковой дальности;

    \item построен и~апробирован алгоритм выбора начального приближения, согласованного с~выбранным семейством траекторий в~расслоении по~числу витков. Алгоритм по~заданной дате старта и~параметрам целевой задачи встречи формирует параметры модельной постановки, выбирает точку оптимальной дальности, вычисляет продолжительность перелёта и~использует линейные преобразования для переноса начальных значений сопряжённых переменных к~целевой задаче. Показано, что в~прикладных задачах Земля--Марс и~Земля--Венера получаемые начальные приближения обеспечивают успешное численное уточнение траекторий, в~том числе при учёте дополнительного импульса скорости в~начальный момент времени и~при продолжении к~постановке с~постоянной скоростью истечения.
\end{enumerate}

\synopsisheading{Научная новизна}{novelty}
Научная новизна работы состоит в~следующем:
\begin{enumerate}[beginpenalty=10000]
    \item разработана методика применения символьной регрессии для построения интерпретируемых конечных формул, аппроксимирующих характеристики решений задачи встречи с~идеально регулируемой тягой и~пригодных для формирования начальных приближений;
    \item предложено описание расслоения решений, в~котором его структура задаётся пересечениями изолиний начальной синодической фазы с~кривой локальных оптимумов в~точках оптимальной дальности;
    \item на~основе инвариантов, связанных с~первыми интегралами расширенной системы уравнений движения, получены условия на~допустимый вид линейных преобразований начальных значений сопряжённых переменных;
    \item разработан алгоритм построения начального приближения, основанный на~согласованном выборе семейства траекторий, продолжительности перелёта и~начальных значений сопряжённых переменных.
\end{enumerate}

\synopsisheading{Теоретическая и практическая значимость}{significance}
Теоретическая значимость работы определяется исследованием модельного многообразия энергетически оптимальных решений, выделением кривой локальных оптимумов и~точек оптимальной дальности. Разработанные конечные формулы и~линейные преобразования задают численно-аналитический переход от~плоской круговой модели к~эллиптическим и~пространственным постановкам.

Практическая значимость состоит в~быстром формировании начальных приближений при массовом проектно-баллистическом анализе межпланетных миссий с~электрореактивными двигательными установками. Аппроксимированное многообразие служит промежуточным представлением между выбором параметров миссии и~численным уточнением траектории. Подход апробирован на~перелётах Земля--Марс и~Земля--Венера и~реализован в~программном инструменте \textit{Interplanetary Low Thrust Trajectories Toolbox} (\texttt{ILTT Toolbox}). Результаты использовались в~исследованиях при поддержке Российского научного фонда, проекты №~19-11-00256 и~№~24-11-00038.

\synopsisheading{Методология и методы исследования}{methods}
Используются методы теоретической и~небесной механики, оптимального управления и~вычислительной математики: принцип максимума Л.С.~Понтрягина, решение двухточечных краевых задач, дискретное продолжение по~граничным условиям, численное интегрирование, анализ параметрических семейств, линейные преобразования сопряжённых переменных и~математическое моделирование. После анализа структуры модельного многообразия для получения конечных формул применяется символьная регрессия.

\synopsisheading{Степень достоверности результатов}{reliability}
Достоверность обеспечивается согласованием постановки с~необходимыми условиями оптимальности, контролем краевых невязок и~устойчивости дискретного продолжения. Конечные формулы проверены на~рабочих областях и~тестовых выборках по~интегральным и~локальным метрикам, а~восстановленные сопряжённые переменные --- повторным интегрированием расширенной системы. Линейные преобразования проверены по~достижению требуемых орбитальных элементов и~побочным деформациям. Прикладная проверка выполнена для задач Земля--Марс и~Земля--Венера с~сопоставлением способов формирования начального приближения.

\noindent\textbf{В первой главе} разработана методика построения и~аппроксимации регулярной параметризованной ветви энергетически оптимальных решений задачи встречи. В~безразмерных переменных движение космического аппарата в~центральном гравитационном поле описывается системой
\begin{equation}
    \dot{\mathbf r}=\mathbf v,
    \qquad
    \dot{\mathbf v}=-\frac{\mathbf r}{r^3}+\mathbf a,
    \label{eq:syn-motion}
\end{equation}
а~критерием оптимальности служит квадратичный функционал
\begin{equation}
    J=\frac12\int_{t_0}^{t_f}\lVert\mathbf a(t)\rVert^2\,dt\longrightarrow\min.
    \label{eq:syn-functional}
\end{equation}
Здесь $\mathbf r$, $\mathbf v$ и~$\mathbf a$ --- безразмерные векторы положения, скорости и~реактивного ускорения, $r=\lVert\mathbf r\rVert$, а~$t_0$ и~$t_f$ --- начальный и~конечный моменты времени. Время перелёта $T=t_f-t_0$ и~состояния на~обоих концах траектории фиксированы.

Для сопряжённых переменных $\mathbf p_r$ и~$\mathbf p_v$ условие стационарности функции Гамильтона--Понтрягина даёт $\mathbf a=\mathbf p_v$, а~необходимые условия оптимальности --- расширенную систему
\begin{equation}
\left\{
\begin{aligned}
    \dot{\mathbf r}&=\mathbf v,&
    \dot{\mathbf v}&=-\frac{\mathbf r}{r^3}+\mathbf p_v,\\
    \dot{\mathbf p}_r&=\frac{1}{r^3}\mathbf p_v
      -\frac{3}{r^5}(\mathbf r\!\cdot\!\mathbf p_v)\mathbf r,&
    \dot{\mathbf p}_v&=-\mathbf p_r.
\end{aligned}
\right.
\label{eq:syn-extended-system}
\end{equation}
Неизвестными параметрами краевой задачи являются начальные значения сопряжённых переменных $\mathbf z_0=(\mathbf p_{r0},\mathbf p_{v0})$, по~которым восстанавливаются управление и~траектория. В~качестве единицы длины $DU$ выбран радиус опорной круговой орбиты, а~единица времени определяется как $TU=\sqrt{DU^3/\mu_d}$, где $\mu_d$ --- размерный гравитационный параметр центрального тела. Такая нормировка сохраняет вид системы~\eqref{eq:syn-extended-system} и~отделяет геометрию решений от~размерных характеристик миссии.

Для выявления регулярной структуры вместо эфемеридных планет введены виртуальные небесные тела на~круговых компланарных орбитах (рис.~\ref{fig:syn-virtual-planets}). Начальное тело движется по~орбите единичного радиуса, а~конечное --- по~орбите радиуса $\kappa$. Его положение в~момент встречи определяется угловой дальностью $\varphi$:
\begin{equation}
\begin{gathered}
    \mathbf r_0=(1,0,0)^{\mathsf T},\qquad
    \mathbf v_0=(0,1,0)^{\mathsf T},\\
    \mathbf r_f=\kappa(\cos\varphi,\sin\varphi,0)^{\mathsf T},\qquad
    \mathbf v_f=\kappa^{-1/2}(-\sin\varphi,\cos\varphi,0)^{\mathsf T}.
\end{gathered}
\label{eq:syn-model-bounds}
\end{equation}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.37\textwidth]{virtual_planet.png}
    \caption{Модельная задача встречи виртуальных небесных тел на~круговых компланарных орбитах}
    \label{fig:syn-virtual-planets}
\end{figure}

Пусть $\boldsymbol\xi\in D_{\mathrm{reg}}\subset\mathbb R^h$ --- вектор $h$ внешних параметров задачи, $\mathbf z_0(\boldsymbol\xi)\in\mathbb R^6$ --- начальные значения сопряжённых переменных, а~$\mathbf c(\boldsymbol\xi)\in\mathbb R^n$ --- вектор $n$ характеристик траектории. Модельное многообразие определено как образ отображения, построенного на~одной регулярной связной ветви энергетически оптимальной двухточечной краевой задачи:
\begin{equation}
    M:D_{\mathrm{reg}}\to\mathbb R^{6+n},\qquad
    M(\boldsymbol\xi)=\bigl(\mathbf z_0(\boldsymbol\xi),\mathbf c(\boldsymbol\xi)\bigr).
    \label{eq:syn-manifold}
\end{equation}
Здесь регулярность понимается в~вычислительном смысле диссертации: на~связной области $D_{\mathrm{reg}}$ одна и~та~же ветвь непрерывно продолжается по~внешним параметрам, а~$\mathbf z_0$ и~$\mathbf c$ изменяются согласованно и~без разрывов. В~основных построениях используется двумерная сетка внешних параметров. В~плоской круговой задаче в~число параметров входят витковая дальность $\lambda=\varphi/(2\pi)$ и~отношение радиусов $\kappa$. Среди характеристик $\mathbf c$ рассматриваются продолжительность перелёта $T$, начальная синодическая фаза и~функционал $J$; начальные значения сопряжённых переменных задаются отдельным вектором $\mathbf z_0$.

Многообразие строится дискретным продолжением по~координатной сетке: решение в~построенном узле служит начальным приближением в~соседнем. Такой обход прослеживает одну регулярную ветвь без перебора всех решений.

После анализа геометрии, сечений и~областей регулярности компоненты аппроксимируются непосредственно либо через иерархию коэффициент-функций. Формулы отбираются символьной регрессией по~точности, сложности и~согласованности, затем проверяются на~рабочей области повторным интегрированием расширенной системы.

\noindent\textbf{Во второй главе} исследовано модельное многообразие в~плоской круговой модели, выделены кривая локальных оптимумов и~точки оптимальной дальности, а~их характеристики представлены конечными формулами. Исходная номограмма перелётов Земля--Марс в~координатах «дата старта --- продолжительность перелёта» расслаивается по~числу витков (рис.~\ref{fig:syn-start-date}), что затрудняет построение общей зависимости в~эфемеридной постановке.

В~модельной задаче дата старта заменяется начальной синодической фазой $\Phi$, а~конечная угловая дальность --- витковой дальностью $\lambda$. Раздельные семейства оказываются координатными представлениями одного односвязного многообразия (рис.~\ref{fig:syn-united-manifold}), где число витков учитывается непрерывным параметром $\lambda$.

    \includegraphics[width=0.79\textwidth]{UnitedManifold.png}

\end{figure}

На~многообразии выделена \textit{кривая локальных оптимумов} (КЛО), состоящая из~решений, для которых при фиксированных $T$ и~$\kappa$ функционал имеет локальный минимум по~витковой дальности. Локально оптимальная витковая дальность обозначается $\lambda^\star$. При фиксированном $\kappa$ КЛО является одномерным подмногообразием построенного двумерного модельного многообразия. Она строится как отдельная ветвь двухточечной задачи с~дополнительным условием на~свободный правый конец, а~не отбором точек из~заранее рассчитанной сетки.

Здесь $\lambda^\star$ --- локально оптимальная дальность, $\widehat\lambda^\star$ --- её значение по~конечной формуле, $\lambda_{\mathrm{corr}}$ --- значение после учёта $R$-преобразований.

При фиксированной дате старта геометрическим аналогом календарной конфигурации служит начальная синодическая фаза. \textit{Точки оптимальной дальности} определены как счётное множество пересечений КЛО с~изолиниями фиксированной начальной синодической фазы (рис.~\ref{fig:syn-optimal-distance}). Каждое пересечение задаёт локально оптимальное значение витковой дальности для данной даты старта; одной фазе могут соответствовать несколько таких точек. Для устранения разрывов фазы по~периоду введена её нормированная непрерывная развёртка $\Psi$.

    \centering
    \includegraphics[width=0.76\textwidth]{Isolines.png}
    \caption{Точки оптимальной дальности как пересечения КЛО с~изолиниями начальной синодической фазы}
    \label{fig:syn-optimal-distance}
\end{figure}

Для основной рабочей области
\begin{equation}
    \lambda^\star\in[0.75,6],
    \qquad
    \kappa\in[0.4,2.5]
    \label{eq:syn-main-domain}
\end{equation}
получены конечные формулы для $T$, $\Psi$, $J$ и~плоского вектора начальных значений сопряжённых переменных $\mathbf z_0^{\mathrm{pl}}$. Знаком $\widehat{\phantom{x}}$ далее обозначаются значения, вычисленные по~конечным формулам. Представительная формула для продолжительности перелёта имеет вид
\begin{equation}
    \widehat T(\lambda^\star,\kappa)=
    \frac{2}{27}\kappa\ln\kappa
    +\lambda^\star\left(\kappa-\frac{\sqrt6}{9}\kappa\ln\kappa\right),
    \label{eq:syn-t-formula}
\end{equation}
причём $\widehat T(\lambda^\star,1)=\lambda^\star$, что согласуется с~предельным режимом совпадающих круговых орбит. Для восстановления зависимости $\widehat{\mathbf z}_0^{\mathrm{pl}}$ от~$\kappa$ использованы эталонные сечения $\kappa_1=0.72$ и~$\kappa_2=1.52$.
Хотя $\Psi=\lambda^\star-T/\kappa^{3/2}$, меньшую ошибку даёт самостоятельная конечная формула $\widehat\Psi=\mathcal A_0^{(\Psi)}(\kappa)+\mathcal A_1^{(\Psi)}(\kappa)\lambda^\star$, где коэффициент-функции $\mathcal A_0^{(\Psi)}$ и~$\mathcal A_1^{(\Psi)}$ зависят от~отношения радиусов $\kappa$.

Для даты старта с~нормированной фазой $\Psi_0=\Phi(t_0)/(2\pi)$ ветвь точек оптимальной дальности выбирается из~уравнений
\begin{equation}
    \widehat\Psi(\widehat\lambda_k^\star,\kappa)=\Psi_0+k,
    \qquad
    \widehat\lambda_k^\star=
    \frac{\Psi_0-\mathcal A_0^{(\Psi)}(\kappa)+k}
         {\mathcal A_1^{(\Psi)}(\kappa)},
    \quad k\in\mathbb Z,
\end{equation}
Затем $\widehat T_k$ находится по~формуле~\eqref{eq:syn-t-formula}, $\widehat J$ оценивает энергетический функционал, а~$\widehat{\mathbf z}_0^{\mathrm{pl}}$ формирует начальное приближение краевой задачи. Для сопряжённых переменных выявлена попарная структура $(p_{rx},p_{vy})$ и~$(p_{ry},p_{vx})$.

\noindent\textit{Область применимости.} Результаты относятся к~прослеженной ветви в~пределах численной сетки. Вычислительный барьер ограничивает устойчивое продолжение, но~не существование решений; условие КЛО не~означает глобальной оптимальности. Конечные формулы дают начальные данные для последующего уточнения краевой задачи.

Таким образом, дискретное продолжение строит регулярное модельное многообразие, геометрический анализ выделяет КЛО и~точки оптимальной дальности, а~конечные формулы преобразуют эту структуру в~приближённое описание для построения начального приближения.

\FloatBarrier
\noindent\textbf{В третьей главе} разработаны три типа линейных $R$-преобразований сопряжённых переменных для перехода от~плоской круговой модели к~постановкам с~изменённым начальным фазовым вектором, эллиптической и~пространственной конечной орбитой. Их композиция переносит модельный сопряжённый вектор к~геометрии целевой задачи встречи. Матрица $R$ строится по~неколлинеарным векторам $\boldsymbol\rho$, $\boldsymbol\nu$ и~$\boldsymbol\eta=\boldsymbol\rho\times\boldsymbol\nu$:
\begin{equation}
    R(\boldsymbol\rho,\boldsymbol\nu)=
    \begin{pmatrix}\boldsymbol\rho&\boldsymbol\nu&\boldsymbol\eta\end{pmatrix},
    \qquad
    \det R=\lVert\boldsymbol\rho\times\boldsymbol\nu\rVert^2>0.
    \label{eq:syn-r-general}
\end{equation}
Вектор преобразуется по~правилу $\mathbf y'=R\mathbf y$, а~сопряжённый ковектор --- согласованно:
\begin{equation}
    \mathbf p'=(R^{\mathsf T})^{-1}\mathbf p.
    \label{eq:syn-r-covector}
\end{equation}
После преобразования расширенная система интегрируется заново. Ограничения на~структуру $R$ получены из~требования контролируемого изменения первых интегралов расширенной системы, включая векторный инвариант
\begin{equation}
    \mathbf M=\mathbf r\times\mathbf p_r+\mathbf v\times\mathbf p_v,
\end{equation}
что позволяет отделить допустимую структуру линейного преобразования от~конкретного способа выбора управляющих параметров.

\noindent\textit{$R$-преобразование I~типа.} Преобразование применяется при изменении начального фазового вектора. Для пар $\mathbf x_a=(\mathbf r_a,\mathbf v_a)$ и~$\mathbf x_b=(\mathbf r_b,\mathbf v_b)$ матрица перехода имеет вид
\begin{equation}
    R_{a\to b}=R_bR_a^{-1},
    \qquad
    \mathbf p_{r,b}=R_{a\to b}^{-\mathsf T}\mathbf p_{r,a},
    \qquad
    \mathbf p_{v,b}=R_{a\to b}^{-\mathsf T}\mathbf p_{v,a}.
    \label{eq:syn-r-type1}
\end{equation}
где $R_a=R(\mathbf r_a,\mathbf v_a)$ и~$R_b=R(\mathbf r_b,\mathbf v_b)$ построены для исходного и~целевого фазовых векторов. В~отличие от~простого поворота, преобразование учитывает масштаб и~взаимное расположение начальных векторов положения и~скорости и~даёт меньшие невязки правого конца.

\noindent\textit{$R$-преобразование II~типа.} При фиксированных $\mathbf r_0$, $\mathbf v_0$ оно задаёт эксцентриситет $e$ и~аргумент перицентра $\omega$ конечной орбиты. Параметр $\zeta$ деформирует матрицу $R_e$, ориентированную поворотом $Q_\chi$ вокруг оси $Oz$:
\begin{equation}
    R_{e\omega}=Q_\chi R_eQ_\chi^{\mathsf T}.
\end{equation}
Угол поворота $\chi$ и~управляющий параметр $\zeta$ вычисляются по~конечным формулам
\begin{equation}
\begin{gathered}
    \chi(\omega)=\frac{\omega}{2}+\frac16\sin2\omega+\frac1{32}\sin4\omega,\\
    \zeta=-\frac{e}{\mathcal A^{(e)}(\kappa,\omega)},
\end{gathered}
\label{eq:syn-r-type2-control}
\end{equation}
где $\mathcal A^{(e)}$ --- коэффициент-функция чувствительности с~гармонической структурой по~$\omega$. При $e=0$ аргумент перицентра вырожден и~полагается $\zeta=0$. Поскольку компоненты $\mathcal A^{(e)}$ пропорциональны $\kappa-1$, эффект преобразования вырождается при сближении радиусов модельных орбит. Побочное изменение витковой дальности компенсируется сдвигом точки модельного многообразия:
\begin{equation}
    \lambda_{\mathrm{corr}}=
    \lambda-\frac{1}{2\pi}\mathcal B_\lambda(\omega,\lambda,\kappa)\zeta.
    \label{eq:syn-lambda-correction}
\end{equation}
Здесь $\mathcal B_\lambda$ --- локальная чувствительность витковой дальности к~$\zeta$. Коррекция уменьшила её RMSE с~$7.31\times10^{-2}$ до~$1.66\times10^{-2}$. Она построена в~окрестности $\zeta=0$ и~не описывает глобальную деформацию при произвольно больших $|\zeta|$.

\noindent\textit{$R$-преобразование III~типа.} Преобразование предназначено для задания наклонения $i$ и~долготы восходящего узла $\Omega$. При фиксированном начальном фазовом векторе используется базовая матрица $R_i(j)$, параметризованная управляющей величиной $j$, а~её ориентация задаётся матрицей $Q_\Omega$ поворота вокруг оси $Oz$ на~угол $\Omega$:
\begin{equation}
    R_i(j)=
    \begin{pmatrix}
        1&0&0\\
        0&(1+j^2)^{-1}&-j(1+j^2)^{-1}\\
        0&j(1+j^2)^{-1}&(1+j^2)^{-1}
    \end{pmatrix},
    \qquad
    R_{i\Omega}=Q_\Omega R_iQ_\Omega^{\mathsf T},
\end{equation}
а~управляющий параметр определяется формулой
\begin{equation}
    j=-\frac{i}{\mathcal A^{(i)}(\kappa,\Omega)}.
    \label{eq:syn-r-type3-control}
\end{equation}
Коэффициент-функция $\mathcal A^{(i)}=\mathcal A_0^{(i)}(\kappa)+\mathcal A_1^{(i)}(\kappa)\cos2\Omega$ задаёт локальную чувствительность наклонения к~$j$. При $i=0$ полагается $j=0$, а~долгота восходящего узла вырождена; при $\kappa\to1$ вырождается пространственный эффект. RMSE задания $i$ и~$\Omega$ составили $3.01\times10^{-3}$ и~$1.12\times10^{-2}$~рад, максимальные ошибки --- $1.22\times10^{-2}$ и~$3.36\times10^{-2}$~рад. Из-за побочных деформаций $\lambda$ и~большой полуоси $a$ преобразование используется как начальное приближение с~последующим уточнением.

Для полной геометрии преобразования объединяются в~композицию. По~$\lambda_{\mathrm{corr}}$ и~$\kappa$ вычисляются модельные сопряжённые векторы, $R_0$ согласует модельный и~реальный начальные фазовые векторы, затем учитываются эллиптичность и~пространственная ориентация:
\begin{equation}
\begin{gathered}
    R_\Sigma=R_{i\Omega}(j,\gamma)
              R_{e\omega}(\zeta,\bar\omega_{\mathrm{rel}})R_0,\\
    \mathbf p_{r0}^{\mathrm{init}}=R_\Sigma^{-\mathsf T}
       \widehat{\mathbf p}_{r0}^{\mathrm{corr}},
    \qquad
    \mathbf p_{v0}^{\mathrm{init}}=R_\Sigma^{-\mathsf T}
       \widehat{\mathbf p}_{v0}^{\mathrm{corr}},
\end{gathered}
\label{eq:syn-r-composition}
\end{equation}
где $\bar\omega_{\mathrm{rel}}=\Omega+\omega-L_0$, $\gamma=\Omega-L_0$, $L_0$ --- истинная долгота начального радиус-вектора. Композиция не является точным аналитическим решением полной задачи, а~формирует геометрически согласованное начальное приближение для численной коррекции. Последовательный эффект трёх типов показан на~рис.~\ref{fig:syn-r-composition}.

\FloatBarrier
\noindent\textbf{В четвёртой главе} конечные формулы и~$R$-преобразования объединены в~алгоритм построения начального приближения по~дате старта и~целевым орбитальным параметрам. Управляющий вектор $\mathbf q=(\lambda,\kappa,\zeta,\chi,j,\gamma)$ имеет геометрический смысл: $(\lambda,\kappa)$ выбирает точку модельного многообразия, $\zeta$ и~$\chi$ задают эксцентриситет и~линию апсид, $j$ и~$\gamma$ --- наклонение и~линию узлов. Это заменяет прямой подбор шести сопряжённых переменных. При композиции аргумент перицентра согласуется с~пространственной ориентацией через относительную долготу $\bar\omega_{\mathrm{rel}}=\Omega+\omega-L_0$.

Алгоритм состоит из~следующих шагов:
\begin{enumerate}
    \item по~эфемеридам для заданной даты старта определяются начальный фазовый вектор и~элементы целевой орбиты, после чего выполняется переход к~безразмерной постановке;
    \item по~начальной синодической фазе находятся три ближайшие точки оптимальной дальности $\lambda_k^\star$, $k\in\{-1,0,1\}$;
    \item исключаются кандидаты вне физически допустимой области $T>0$ и~области применимости формул, среди остальных выбирается вариант, удовлетворяющий ограничениям и~дающий лучшее значение критерия;
    \item точка КЛО корректируется по~формуле~\eqref{eq:syn-lambda-correction}, затем вычисляются $\widehat T$, $\widehat J$ и~$\widehat{\mathbf z}_0^{\mathrm{pl}}$;
    \item композиция~\eqref{eq:syn-r-composition} переводит модельное решение в~начальный вектор расширенной системы $\mathbf y_0^{\mathrm{init}}$ эфемеридной задачи;
    \item $\mathbf y_0^{\mathrm{init}}$ и~$\widehat T$ используются для последующего численного решения двухточечной краевой задачи.
\end{enumerate}
Если допустим только один кандидат, выбор на~третьем шаге однозначен.

Поэтому сравнение характеризует конкретную реализацию и~сетку дат, а~преимущество предлагаемого метода состоит в~отсутствии заранее заданного номера ветви.

Полученное ИРТ-решение используется как исходная точка для двух последовательных продолжений к~более прикладной постановке. Первое продолжение вводит дополнительный импульс скорости. При параметре $\tau_1\in[0,1]$ начальная скорость задаётся как
\begin{equation}
    \mathbf v(t_0)=\mathbf v_C(t_0)
    +\tau_1v_{\delta,\max}\mathbf n_\delta(\tau_1),
    \qquad
    \mathbf n_\delta(\tau_1)=
    \frac{\mathbf p_{v0}(\tau_1)}{\lVert\mathbf p_{v0}(\tau_1)\rVert}.
    \label{eq:syn-vdelta-continuation}
\end{equation}
Здесь $\mathbf v_C(t_0)$ --- скорость тела отправления, $v_{\delta,\max}$ --- заданный предельный модуль дополнительного импульса. При $\tau_1=0$ дополнительный импульс отсутствует; при $\tau_1=1$ достигается его предельное значение. Направление выбирается согласованно с~условием трансверсальности, а~конечные формулы и~$R$-преобразования задают начальное решение для $\tau_1=0$.

Второе продолжение переводит полученное ИРТ-решение с~дополнительным импульсом к~модели постоянной скорости истечения. Квадратичный функционал деформируется в~линейный по~модулю тяги:
\begin{equation}
    J_{\tau_2}=\int_{t_0}^{t_0+T}
    \left((1-\tau_2)\frac{\lVert\mathbf a(t)\rVert^2}{2}
    +\tau_2\lVert\mathbf a(t)\rVert\right)dt,
    \qquad \tau_2\in[0,1].
    \label{eq:syn-psi-continuation}
\end{equation}
Значения $\tau_2=0$ и~$\tau_2=1$ соответствуют ИРТ- и~ПСИ-постановкам. Для обоих продолжений изменение начального вектора $\mathbf z_0$ определяется из~системы невязок $\mathbf F(\mathbf z_0,\tau_\ell)=\mathbf0$:
\begin{equation}
    \frac{d\mathbf z_0}{d\tau_\ell}=
    -\left(\frac{\partial\mathbf F}{\partial\mathbf z_0}\right)^{-1}
    \frac{\partial\mathbf F}{\partial\tau_\ell},
    \qquad \ell=1,2.
    \label{eq:syn-two-continuations}
\end{equation}
На~примере Земля--Венера для начальной массы 156~кг получено опорное ПСИ-решение продолжительностью 390.8~суток с~моторным временем 195.2~суток, затратами топлива 41.77~кг и~дополнительным импульсом 2.67~км/с.

Конечные формулы, $R$-преобразования, интегрирование расширенной системы и~уточнение в~параметрах $\mathbf q$ реализованы в~комплексе \texttt{ILTT Toolbox}, что обеспечивает воспроизводимость вычислительной схемы. Последующее уточнение выполняется в~целевой модели движения и~двигательной установки.

\begin{center}
    \textbf{ОСНОВНЫЕ РЕЗУЛЬТАТЫ И ВЫВОДЫ}
\end{center}

\begin{enumerate}
    \item Построено регулярное модельное многообразие энергетически оптимальных решений задачи встречи с~идеально регулируемой тягой. Показано, что расслоение многовитковых решений переходит в~односвязное многообразие, на~котором выделены кривая локальных оптимумов и~точки оптимальной дальности. Вычислительный барьер определяет границу устойчивого продолжения выбранной ветви, но~не существования решений.

    \item В~области $\lambda^\star\in[0.75,6]$, $\kappa\in[0.4,2.5]$ получены конечные формулы для продолжительности перелёта, непрерывной фазы, функционала и~начальных значений сопряжённых переменных. RMSE составила $2.32\times10^{-2}$ для $\widehat T$, $1.88\times10^{-2}$ для $\widehat\Psi$, $1.24\times10^{-4}$ для $\widehat J$ и~$8.71\times10^{-4}$ для $\widehat{\mathbf z}_0^{\mathrm{pl}}$.

    \item Разработаны три типа линейных $R$-преобразований: для изменения начального фазового вектора, задания эксцентриситета и~линии апсид, наклонения и~линии узлов конечной орбиты. Установлены их побочные деформации и~вырожденные случаи; коррекция уменьшила RMSE витковой дальности с~$7.31\times10^{-2}$ до~$1.66\times10^{-2}$.

    \item Предложен алгоритм, который по~дате старта проверяет не~более трёх точек оптимальной дальности и~преобразует модельный сопряжённый вектор к~целевой геометрии. На~сетке из~100 марсианских дат получено 100\% успешных уточнений при среднем времени $0.636$~с против $1.89$~с для продолжения по~$\mu$. ИРТ-решение последовательно продолжено по~дополнительному импульсу скорости и~к~ПСИ-постановке; для перелёта Земля--Венера получено опорное решение с~затратами топлива 41.77~кг и~дополнительным импульсом 2.67~км/с. Схема реализована в~\texttt{ILTT Toolbox}.
\end{enumerate}
