\synopsisheading{Актуальность темы исследования}{actuality}
Проектирование межпланетных перелётов космических аппаратов с~электрореактивными двигательными установками находится на~стыке небесной механики, оптимального управления и~прикладного проектно-баллистического анализа. Высокий удельный импульс таких установок позволяет реализовывать миссии при ограниченной массе рабочего тела, однако длительное управляемое движение существенно увеличивает трудоёмкость баллистического проектирования. Уже на~ранних этапах анализа миссии требуется многократно оценивать допустимые даты старта, продолжительности перелёта, энергетические характеристики траекторий и~параметры управления.

Для предварительного выбора межпланетных траекторий традиционно используются номограммы, связывающие дату старта, продолжительность перелёта и~энергетические характеристики. В~случае непрерывной тяги такая картина имеет дополнительную особенность: решения двухточечной краевой задачи расслаиваются по~числу витков. Поэтому необходимо выбрать не~только окно старта, но~и~семейство траекторий, а~затем сформировать согласованное с~ним начальное приближение для непрямого метода оптимизации. Непосредственное решение задачи с~нуля для каждого набора проектных параметров требует значительных вычислительных затрат и~может приводить к~переходу на~другую ветвь решений.

\synopsisheading{Степень разработанности темы исследования}{elaboration}
Теоретической основой непрямой оптимизации служит принцип максимума Л.С.~Понтрягина~\cite{pontryagin_optimal_processes_ru_1976}. Его применение к~задаче перелёта с~непрерывной тягой приводит к~расширенной системе уравнений и~двухточечной краевой задаче, чувствительной к~начальным значениям сопряжённых переменных. Методы продолжения позволяют прослеживать отдельные ветви решений, но~сами по~себе не~дают компактного представления большого массива рассчитанных траекторий, пригодного для быстрого проектного применения.

Отечественная традиция постановки и~численного исследования задач космической динамики связана со~школой Д.Е.~Охоцимского и~работами по~динамике космического полёта~\cite{okhotsimsky_dynamics_1968}. Методические вопросы проектирования траекторий с~малой тягой и~баллистики межпланетных перелётов с~электрореактивными двигателями развивались в~работах Т.М.~Энеева и~соавторов~\cite{eneev_methodical_low_thrust_1996,eneev_ballistic_electric_2000}. Для исследования многовитковых перелётов В.Г.~Петуховым применены методы продолжения по~параметрам граничных условий, позволяющие прослеживать отдельные ветви решений~\cite{petukhov_multi_orbit_ru_2004,petukhov_method_ru_2012}. При массовом проектном анализе при этом сохраняется необходимость многократного решения чувствительных краевых задач и~согласованного выбора ветви.

Для межпланетных перелётов с~малым числом витков, существенным изменением радиуса орбиты и~непериодическим управлением универсальные аналитические решения отсутствуют. Перспективным является промежуточное численно-аналитическое представление, которое сохраняет структуру множества решений, допускает интерпретацию через компактные конечные формулы и~содержит начальные значения сопряжённых переменных. Символьная регрессия~\cite{cranmer_pysr_2023} используется в~работе как управляемый инструмент получения таких формул после механического анализа, выбора параметризации и~проверки поведения выражений на~рабочей области.

В~диссертации в~качестве регулярной модельной постановки рассматривается энергетически оптимальная задача встречи с~идеально регулируемой непрерывной тягой (ИРТ). Она сохраняет основные трудности непрямой оптимизации и~одновременно позволяет отделить структуру решений от~календарных и~эфемеридных особенностей конкретной миссии. Построенное для этой задачи модельное многообразие используется как связующее звено между массовым расчётом траекторий, конечными формулами и~начальным приближением для прикладной задачи встречи. Поэтому разработка численно-аналитического метода, обеспечивающего согласованный выбор семейства решений и~построение начального приближения, является актуальной задачей динамики космического полёта и~баллистического проектирования.

\synopsisheading{Цель работы}{aim}
Цель работы --- разработать и~апробировать численно-аналитический метод формирования начального приближения для энергетически оптимального межпланетного перелёта с~идеально регулируемой тягой. Метод должен обеспечивать выбор заданного семейства траекторий в~расслоении по~числу витков на~основе модельного многообразия решений задачи встречи.

Для достижения поставленной цели необходимо решить следующие \textbf{задачи}:
\begin{enumerate}[beginpenalty=10000]
    \item разработать методику построения, исследования и~аппроксимации модельного многообразия решений задачи встречи с~идеально регулируемой тягой, позволяющую описывать расслоение по~числу витков;
    \item исследовать модельное многообразие решений в~плоской круговой модели движения небесных тел, выделить точки оптимальной дальности и~построить конечные формулы, связывающие параметры компланарного перелёта между круговыми орбитами с~характеристиками траектории и~начальными значениями сопряжённых переменных;
    \item разработать линейные преобразования начальных значений сопряжённых переменных, позволяющие учитывать изменение начального фазового вектора, эллиптичность и~пространственную ориентацию конечной орбиты при переходе от~плоской круговой модельной постановки к~целевой задаче встречи;
    \item построить и~апробировать алгоритм формирования начального приближения, согласованного с~выбранным семейством траекторий, по~заданной дате старта и~параметрам целевой задачи встречи, в~том числе для перелётов Земля--Марс и~Земля--Венера, постановок с~дополнительным импульсом скорости в~начальный момент времени и~последующего продолжения к~постановке с~постоянной скоростью истечения.
\end{enumerate}

\synopsisheading{Объект и предмет исследования}{objectsubject}
Объектом исследования являются семейства энергетически оптимальных решений задач встречи для межпланетных перелётов космического аппарата с~идеально регулируемой непрерывной тягой, рассматриваемые с~точки зрения расслоения по~числу витков. Предмет исследования составляют численно-аналитические методы построения, исследования, аппроксимации и~использования модельного многообразия решений, позволяющие описывать это расслоение и~формировать начальное приближение, согласованное с~выбранным семейством траекторий.

\synopsisheading{Положения, выносимые на защиту}{defpositions}
На~защиту выносятся следующие положения:
\begin{enumerate}[beginpenalty=10000]
    \item предложена методика исследования расслоения решений задачи встречи с~идеально регулируемой тягой по~числу витков. Методика основана на~построении модельного многообразия решений двухточечной краевой задачи с~помощью дискретного продолжения по~параметрической сетке и~последующей аппроксимации его характеристик. В~рамках методики выделены точки оптимальной дальности, используемые как основной объект аппроксимации и~выбора начального приближения;

    \item для плоской круговой модели движения небесных тел предложены конечные формулы, полученные с~использованием символьной регрессии и~позволяющие по~параметрам компланарного перелёта между круговыми орбитами выбирать точку оптимальной дальности и~вычислять характеристики ИРТ-траектории. Предложенные формулы связывают параметры модельной задачи с~продолжительностью перелёта, значением квадратичного функционала, начальной синодической фазой и~начальными значениями сопряжённых переменных;

    \item разработан аппарат линейных преобразований начальных значений сопряжённых переменных, используемый при переходе от~плоской круговой модельной постановки к~целевой задаче встречи. Эти преобразования позволяют учитывать изменение начального фазового вектора, эллиптичность и~пространственную ориентацию конечной орбиты. Для управляющих параметров этих преобразований предложены конечные формулы, а~также построена линейная коррекция витковой дальности;

    \item построен и~апробирован алгоритм выбора начального приближения, согласованного с~выбранным семейством траекторий в~расслоении по~числу витков. Алгоритм по~заданной дате старта и~параметрам целевой задачи встречи формирует параметры модельной постановки, выбирает точку оптимальной дальности, вычисляет продолжительность перелёта и~использует линейные преобразования для переноса начальных значений сопряжённых переменных к~целевой задаче. Показано, что в~прикладных задачах Земля--Марс и~Земля--Венера получаемые начальные приближения обеспечивают успешное численное уточнение траекторий, в~том числе при учёте дополнительного импульса скорости в~начальный момент времени и~при продолжении к~постановке с~постоянной скоростью истечения.
\end{enumerate}

\synopsisheading{Научная новизна}{novelty}
Научная новизна работы состоит в~следующем:
\begin{enumerate}[beginpenalty=10000]
    \item разработана методика применения символьной регрессии для построения интерпретируемых конечных формул, аппроксимирующих характеристики решений задачи встречи с~идеально регулируемой тягой и~пригодных для формирования начальных приближений;
    \item предложено описание расслоения решений, в~котором его структура задаётся пересечениями изолиний начальной синодической фазы с~кривой локальных оптимумов в~точках оптимальной дальности;
    \item на~основе инвариантов, связанных с~первыми интегралами расширенной системы уравнений движения, получены условия на~допустимый вид линейных преобразований начальных значений сопряжённых переменных;
    \item разработан алгоритм построения начального приближения, основанный на~согласованном выборе семейства траекторий, продолжительности перелёта и~начальных значений сопряжённых переменных.
\end{enumerate}

\synopsisheading{Теоретическая и практическая значимость}{significance}
Теоретическая значимость работы определяется исследованием структуры модельного многообразия энергетически оптимальных решений задачи встречи, выделением кривой локальных оптимумов и~точек оптимальной дальности, а~также построением конечных формул для характеристик траекторий и~начальных значений сопряжённых переменных. Разработанные линейные преобразования задают численно-аналитический способ перехода от~плоской круговой модели к~эллиптическим и~пространственным постановкам.

Практическая значимость состоит в~возможности быстрого формирования начальных приближений при массовом проектно-баллистическом анализе межпланетных миссий с~электрореактивными двигательными установками. Аппроксимированное модельное многообразие используется как промежуточное представление между предварительным выбором параметров миссии и~численным уточнением траектории. Подход апробирован на~перелётах Земля--Марс и~Земля--Венера и~реализован в~программном инструменте \textit{Interplanetary Low Thrust Trajectories Toolbox} (\texttt{ILTT Toolbox}). Результаты получены и~использовались в~исследованиях, выполнявшихся при поддержке Российского научного фонда, проекты №~19-11-00256 и~№~24-11-00038.

\synopsisheading{Методология и методы исследования}{methods}
В~работе используются методы теоретической механики, небесной механики, оптимального управления и~вычислительной математики: принцип максимума Л.С.~Понтрягина, решение двухточечных краевых задач, дискретное продолжение по~параметрам граничных условий, численное интегрирование расширенной системы, анализ параметрических семейств решений, линейные преобразования начальных значений сопряжённых переменных и~математическое моделирование. Символьная регрессия применяется как инструмент получения конечных формул после выбора параметризации и~анализа структуры модельного многообразия.

\synopsisheading{Степень достоверности результатов}{reliability}
Достоверность результатов обеспечивается несколькими уровнями проверки. Во-первых, математическая постановка согласована с~необходимыми условиями оптимальности, а~при построении модельного многообразия контролируются краевые невязки двухточечной задачи и~устойчивость перехода между соседними точками параметрической сетки. Во-вторых, конечные формулы проверены на~рабочих областях параметров и~тестовых выборках по~интегральным и~локальным метрикам ошибок; для восстановленных начальных значений сопряжённых переменных выполнено повторное интегрирование расширенной системы. В-третьих, свойства линейных преобразований проверены по~достижению требуемых орбитальных элементов и~по~побочным изменениям витковой дальности и~большой полуоси конечной орбиты. Наконец, прикладная проверка включает задачи Земля--Марс и~Земля--Венера и~сравнение способов формирования начального приближения.

В~четвёртой главе конечные формулы и~преобразования используются для построения начального приближения в~прикладных задачах баллистического проектирования.

\noindent\textbf{В первой главе} сформулирована методика построения, исследования и~аппроксимации модельного многообразия решений энергетически оптимальных задач встречи. Результатом её применения служит регулярная параметризованная ветвь решений, пригодная для последующего геометрического анализа и~аппроксимации. В~безразмерных переменных движение космического аппарата в~центральном гравитационном поле описывается системой
\begin{equation}
    \dot{\mathbf r}=\mathbf v,
    \qquad
    \dot{\mathbf v}=-\frac{\mathbf r}{r^3}+\mathbf a,
    \label{eq:syn-motion}
\end{equation}
а~критерием оптимальности служит квадратичный функционал
\begin{equation}
    J=\frac12\int_{t_0}^{t_f}\lVert\mathbf a(t)\rVert^2\,dt\longrightarrow\min.
    \label{eq:syn-functional}
\end{equation}
Здесь $\mathbf r$, $\mathbf v$ и~$\mathbf a$ --- безразмерные векторы положения, скорости и~реактивного ускорения, $r=\lVert\mathbf r\rVert$, а~$t_0$ и~$t_f$ --- начальный и~конечный моменты времени. Время перелёта $T=t_f-t_0$ и~состояния на~обоих концах траектории фиксированы.

Для сопряжённых переменных $\mathbf p_r$ и~$\mathbf p_v$ функция Гамильтона--Понтрягина имеет вид
\begin{equation}
    H=\mathbf p_r\!\cdot\!\mathbf v
    +\mathbf p_v\!\cdot\!\left(-\frac{\mathbf r}{r^3}+\mathbf a\right)
    -\frac12\lVert\mathbf a\rVert^2.
\end{equation}
Условие стационарности даёт $\mathbf a=\mathbf p_v$, после чего необходимые условия оптимальности записываются как расширенная система
\begin{equation}
\left\{
\begin{aligned}
    \dot{\mathbf r}&=\mathbf v,&
    \dot{\mathbf v}&=-\frac{\mathbf r}{r^3}+\mathbf p_v,\\
    \dot{\mathbf p}_r&=\frac{1}{r^3}\mathbf p_v
      -\frac{3}{r^5}(\mathbf r\!\cdot\!\mathbf p_v)\mathbf r,&
    \dot{\mathbf p}_v&=-\mathbf p_r.
\end{aligned}
\right.
\label{eq:syn-extended-system}
\end{equation}
Неизвестными параметрами двухточечной краевой задачи являются начальные значения сопряжённых переменных
\begin{equation}
    \mathbf z_0=(\mathbf p_{r0},\mathbf p_{v0}).
    \label{eq:syn-z0}
\end{equation}
По~ним восстанавливаются оптимальное управление и~вся траектория. В~качестве единицы длины $DU$ выбран радиус опорной круговой орбиты, а~единица времени определяется как $TU=\sqrt{DU^3/\mu_d}$, где $\mu_d$ --- размерный гравитационный параметр центрального тела. Такая нормировка сохраняет вид системы~\eqref{eq:syn-extended-system} и~отделяет геометрию решений от~размерных характеристик миссии.

Для выявления регулярной структуры вместо эфемеридных планет введены виртуальные небесные тела на~круговых компланарных орбитах (рис.~\ref{fig:syn-virtual-planets}). Начальное тело движется по~орбите единичного радиуса, а~конечное --- по~орбите радиуса $\kappa$. Его положение в~момент встречи определяется угловой дальностью $\varphi$:
\begin{equation}
\begin{gathered}
    \mathbf r_0=(1,0,0)^{\mathsf T},\qquad
    \mathbf v_0=(0,1,0)^{\mathsf T},\\
    \mathbf r_f=\kappa(\cos\varphi,\sin\varphi,0)^{\mathsf T},\qquad
    \mathbf v_f=\kappa^{-1/2}(-\sin\varphi,\cos\varphi,0)^{\mathsf T}.
\end{gathered}
\label{eq:syn-model-bounds}
\end{equation}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.37\textwidth]{virtual_planet.png}
    \caption{Модельная задача встречи виртуальных небесных тел на~круговых компланарных орбитах}
    \label{fig:syn-virtual-planets}
\end{figure}

Пусть $\boldsymbol\xi\in D_{\mathrm{reg}}\subset\mathbb R^h$ --- вектор $h$ внешних параметров задачи, $\mathbf z_0(\boldsymbol\xi)\in\mathbb R^6$ --- начальные значения сопряжённых переменных, а~$\mathbf c(\boldsymbol\xi)\in\mathbb R^n$ --- вектор $n$ характеристик траектории. Модельное многообразие определено как образ отображения, построенного на~одной регулярной связной ветви энергетически оптимальной двухточечной краевой задачи:
\begin{equation}
    M:D_{\mathrm{reg}}\to\mathbb R^{6+n},\qquad
    M(\boldsymbol\xi)=\bigl(\mathbf z_0(\boldsymbol\xi),\mathbf c(\boldsymbol\xi)\bigr).
    \label{eq:syn-manifold}
\end{equation}
Здесь регулярность понимается в~вычислительном смысле диссертации: на~связной области $D_{\mathrm{reg}}$ одна и~та~же ветвь непрерывно продолжается по~внешним параметрам, а~$\mathbf z_0$ и~$\mathbf c$ изменяются согласованно и~без разрывов. В~основных построениях используется двумерная сетка внешних параметров. В~плоской круговой задаче в~число параметров входят витковая дальность $\lambda=\varphi/(2\pi)$ и~отношение радиусов $\kappa$. Среди характеристик $\mathbf c$ рассматриваются продолжительность перелёта $T$, начальная синодическая фаза и~функционал $J$; начальные значения сопряжённых переменных задаются отдельным вектором $\mathbf z_0$.

Численное построение начинается с~базового решения и~выполняется методом дискретного продолжения по~координатной сетке: решение в~уже построенном узле используется как начальное приближение в~соседнем. Такой локальный обход прослеживает одну и~ту~же регулярную ветвь и~не предполагает перебора всех формально возможных решений. Схема метода приведена на~рис.~\ref{fig:syn-continuation}.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.70\textwidth]{continuation_paths.png}
    \caption{Дискретное продолжение регулярной ветви на~двумерной сетке внешних параметров}
    \label{fig:syn-continuation}
\end{figure}

После построения многообразия анализируются его геометрия, естественные сечения и~области регулярности. Для гладких низкоразмерных зависимостей компоненты аппроксимируются непосредственно; для более сложных зависимостей используется иерархия коэффициент-функций. Конечные формулы отбираются методом символьной регрессии с~учётом точности, сложности, размерной и~кинематической согласованности. Общий цикл завершается проверкой формул на~рабочей области, включая повторное интегрирование расширенной системы.

\FloatBarrier
\noindent\textbf{Во второй главе} исследовано модельное многообразие энергетически оптимальных решений в~плоской круговой модели. Геометрический анализ позволяет выделить кривую локальных оптимумов и~точки оптимальной дальности, а~затем представить характеристики этих точек конечными формулами. Исходной мотивацией послужило расслоение номограммы перелётов Земля--Марс в~координатах «дата старта --- продолжительность перелёта» по~числу витков траектории (рис.~\ref{fig:syn-start-date}). В~эфемеридной постановке эти семейства технически раздельны, поэтому непосредственное построение компактной общей зависимости затруднено.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.82\textwidth]{StartDate_rebuilt2.png}
    \caption{Расслоение изолиний номограммы требуемого запаса рабочего тела для перелёта Земля--Марс}
    \label{fig:syn-start-date}
\end{figure}

После замены реальных планет виртуальными телами календарная дата старта заменяется начальной синодической фазой $\Phi$, а~конечная угловая дальность --- витковой дальностью $\lambda$. При фиксированном $\kappa$ решение характеризуется величинами $\Phi$, $\lambda$, $T$ и~$J$.
Показано, что визуально раздельные семейства являются координатными представлениями одного односвязного модельного многообразия (рис.~\ref{fig:syn-united-manifold}). Тем самым число витков учитывается непрерывным параметром $\lambda$, а~не выбором независимого набора решений.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.79\textwidth]{UnitedManifold.png}
    \caption{Односвязное модельное многообразие в~координатах «продолжительность перелёта --- витковая дальность»}
    \label{fig:syn-united-manifold}
\end{figure}

На~многообразии выделена \textit{кривая локальных оптимумов} (КЛО), состоящая из~решений, для которых при фиксированных $T$ и~$\kappa$ функционал имеет локальный минимум по~витковой дальности. Локально оптимальная витковая дальность обозначается $\lambda^\star$. При фиксированном $\kappa$ КЛО является одномерным подмногообразием построенного двумерного модельного многообразия. Она строится как отдельная ветвь двухточечной задачи с~дополнительным условием на~свободный правый конец, а~не отбором точек из~заранее рассчитанной сетки.

В~дальнейшем $\lambda$ обозначает произвольную витковую дальность, $\lambda^\star$ --- её локально оптимальное значение, $\widehat\lambda^\star$ --- значение, найденное по~конечной формуле, а~$\lambda_{\mathrm{corr}}$ --- значение после коррекции, учитывающей действие $R$-преобразований.

При фиксированной дате старта геометрическим аналогом календарной конфигурации служит начальная синодическая фаза. \textit{Точки оптимальной дальности} определены как счётное множество пересечений КЛО с~изолиниями фиксированной начальной синодической фазы (рис.~\ref{fig:syn-optimal-distance}). Каждое пересечение задаёт локально оптимальное значение витковой дальности для данной даты старта; одной фазе могут соответствовать несколько таких точек. Для устранения разрывов фазы по~периоду введена её нормированная непрерывная развёртка $\Psi$.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.76\textwidth]{Isolines.png}
    \caption{Точки оптимальной дальности как пересечения КЛО с~изолиниями начальной синодической фазы}
    \label{fig:syn-optimal-distance}
\end{figure}

Для построенной численной рабочей области КЛО получены конечные формулы для $T$, $\Psi$, $J$ и~плоского вектора начальных значений сопряжённых переменных $\mathbf z_0^{\mathrm{pl}}$. Знаком $\widehat{\phantom{x}}$ далее обозначаются значения, вычисленные по~конечным формулам. Представительная формула для продолжительности перелёта имеет компактный вид
\begin{equation}
    \widehat T(\lambda^\star,\kappa)=
    \frac{2}{27}\kappa\ln\kappa
    +\lambda^\star\left(\kappa-\frac{\sqrt6}{9}\kappa\ln\kappa\right),
    \label{eq:syn-t-formula}
\end{equation}
причём $\widehat T(\lambda^\star,1)=\lambda^\star$, что согласуется с~предельным режимом совпадающих круговых орбит. Для восстановления зависимости $\widehat{\mathbf z}_0^{\mathrm{pl}}$ от~$\kappa$ использованы эталонные сечения $\kappa_1=0.72$ и~$\kappa_2=1.52$.
\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.82\textwidth]{main_T_isolines.png}
    \caption{Изолинии продолжительности перелёта на~основной рабочей области параметров $(\lambda^\star,\kappa)$}
    \label{fig:syn-main-t-isolines}
\end{figure}

Непрерывная фаза связана с~продолжительностью кинематическим соотношением
\begin{equation}
    \Psi=\lambda^\star-\frac{T}{\kappa^{3/2}},
\end{equation}
но~самостоятельная конечная формула $\widehat\Psi=\mathcal A_0^{(\Psi)}(\kappa)+\mathcal A_1^{(\Psi)}(\kappa)\lambda^\star$, где $\mathcal A_0^{(\Psi)}$ и~$\mathcal A_1^{(\Psi)}$ --- коэффициент-функции, зависящие от~$\kappa$, обеспечивает меньшую ошибку, чем подстановка $\widehat T$ в~эту связь.

Для заданной даты старта с~нормированной фазой $\Psi_0=\Phi(t_0)/(2\pi)$ выбор ветви точек оптимальной дальности выполняется из~уравнений
\begin{equation}
    \widehat\Psi(\widehat\lambda_k^\star,\kappa)=\Psi_0+k,
    \qquad
    \widehat\lambda_k^\star=
    \frac{\Psi_0-\mathcal A_0^{(\Psi)}(\kappa)+k}
         {\mathcal A_1^{(\Psi)}(\kappa)},
    \quad k\in\mathbb Z,
\end{equation}
после чего $\widehat T_k$ находится по~формуле~\eqref{eq:syn-t-formula}. Формула $\widehat J$ позволяет оценить значение энергетического функционала, а~$\widehat{\mathbf z}_0^{\mathrm{pl}}$ формирует начальное приближение для решения краевой задачи. Для сопряжённых переменных выявлена попарная структура $(p_{rx},p_{vy})$ и~$(p_{ry},p_{vx})$. Для основной и~переходной областей построены отдельные наборы конечных формул; формулы переходной области при $\lambda^\star<0.75$ менее точны, но~обеспечивают устойчивое прохождение через малые витковые дальности.

Качество формул проверено на~тестовой выборке по~среднеквадратической ошибке (RMSE), средней абсолютной ошибке (MAE) и~максимальной абсолютной ошибке $\max|\Delta|$, где $\Delta$ --- ошибка аппроксимации; $S$ обозначает характерный масштаб величины. Все величины табл.~\ref{tab:syn-main-errors} относятся к~безразмерной модельной постановке.

\noindent\textit{Область применимости.} Полученные результаты относятся к~прослеженной регулярной ветви в~пределах использованной численной сетки. Вычислительный барьер определяет границу устойчивого продолжения и~не~доказывает отсутствия решений за~её пределами; условие КЛО также не~означает глобальной оптимальности траектории. Конечные формулы служат источником начальных данных для последующего уточнения и~не~заменяют решение краевой задачи.

Таким образом, первые две главы дают связанный результат: метод дискретного продолжения строит регулярное модельное многообразие, его геометрический анализ выделяет КЛО и~точки оптимальной дальности, а~конечные формулы преобразуют эти структуры в~компактное приближённое описание, пригодное для последующего переноса на~более общие постановки и~построения начального приближения.

\FloatBarrier
\noindent\textbf{В третьей главе} разработаны линейные преобразования начальных значений сопряжённых переменных, обеспечивающие переход от~плоской круговой модельной задачи к~постановкам с~изменённым начальным фазовым вектором, эллиптической и~пространственной конечной орбитой. Результатом главы служит композиция трёх типов $R$-преобразований, которая переносит модельный сопряжённый вектор к~геометрии целевой задачи встречи. Матрица $R$ строится по~двум неколлинеарным векторам $\boldsymbol\rho$, $\boldsymbol\nu$ и~их векторному произведению $\boldsymbol\eta=\boldsymbol\rho\times\boldsymbol\nu$:
\begin{equation}
    R(\boldsymbol\rho,\boldsymbol\nu)=
    \begin{pmatrix}\boldsymbol\rho&\boldsymbol\nu&\boldsymbol\eta\end{pmatrix},
    \qquad
    \det R=\lVert\boldsymbol\rho\times\boldsymbol\nu\rVert^2>0.
    \label{eq:syn-r-general}
\end{equation}
Вектор преобразуется по~правилу $\mathbf y'=R\mathbf y$, а~сопряжённый ковектор --- согласованно:
\begin{equation}
    \mathbf p'=(R^{\mathsf T})^{-1}\mathbf p.
    \label{eq:syn-r-covector}
\end{equation}
После преобразования начального вектора расширенная система интегрируется заново. Ограничения на~структуру $R$ получены из~требования контролируемого изменения первых интегралов расширенной системы; в~частности, использован векторный инвариант
\begin{equation}
    \mathbf M=\mathbf r\times\mathbf p_r+\mathbf v\times\mathbf p_v.
\end{equation}
Этот аппарат позволяет отделить допустимую структуру линейного преобразования от~конкретного способа выбора его управляющих параметров.

Предложена классификация из~трёх типов.

\noindent\textit{$R$-преобразование I~типа.} Преобразование применяется при изменении начального фазового вектора. Для пар $\mathbf x_a=(\mathbf r_a,\mathbf v_a)$ и~$\mathbf x_b=(\mathbf r_b,\mathbf v_b)$ матрица перехода имеет вид
\begin{equation}
    R_{a\to b}=R_bR_a^{-1},
    \qquad
    \mathbf p_{r,b}=R_{a\to b}^{-\mathsf T}\mathbf p_{r,a},
    \qquad
    \mathbf p_{v,b}=R_{a\to b}^{-\mathsf T}\mathbf p_{v,a}.
    \label{eq:syn-r-type1}
\end{equation}
где $R_a=R(\mathbf r_a,\mathbf v_a)$ и~$R_b=R(\mathbf r_b,\mathbf v_b)$ --- матрицы, построенные по~формуле~\eqref{eq:syn-r-general} для исходного и~целевого фазовых векторов соответственно.
В~отличие от~простого поворота, преобразование учитывает изменение масштаба и~взаимного расположения начальных векторов положения и~скорости. Сравнение на~рис.~\ref{fig:syn-r-type1-compare} показывает, что согласованное преобразование фазовой и~сопряжённой частей даёт существенно меньшие невязки правого конца.

    \label{fig:syn-r-type1-compare}
\end{figure}

\noindent\textit{$R$-преобразование II~типа.} Преобразование действует только на~$\mathbf p_{r0}$ и~$\mathbf p_{v0}$ при фиксированных $\mathbf r_0$, $\mathbf v_0$ и~задаёт эксцентриситет $e$ и~аргумент перицентра $\omega$ конечной орбиты. Управляющая величина $\zeta$ задаёт деформацию базовой диагональной матрицы $R_e$, а~её ориентация определяется матрицей $Q_\chi$ поворота вокруг оси $Oz$ на~угол $\chi$:
\begin{equation}
    R_{e\omega}=Q_\chi R_eQ_\chi^{\mathsf T}.
\end{equation}
Угол поворота $\chi$ и~управляющий параметр $\zeta$ вычисляются по~конечным формулам
\begin{equation}
\begin{gathered}
    \chi(\omega)=\frac{\omega}{2}+\frac16\sin2\omega+\frac1{32}\sin4\omega,\\
    \zeta=-\frac{e}{\mathcal A^{(e)}(\kappa,\omega)},
\end{gathered}
\label{eq:syn-r-type2-control}
\end{equation}
где $\mathcal A^{(e)}$ --- коэффициент-функция чувствительности, имеющая гармоническую структуру по~$\omega$. При $e=0$ аргумент перицентра вырожден и~полагается $\zeta=0$. Поскольку компоненты $\mathcal A^{(e)}$ пропорциональны $\kappa-1$, эффект преобразования вырождается при сближении радиусов модельных орбит. Побочное изменение витковой дальности компенсируется предварительным сдвигом точки модельного многообразия:
\begin{equation}
    \lambda_{\mathrm{corr}}=
    \lambda-\frac{1}{2\pi}\mathcal B_\lambda(\omega,\lambda,\kappa)\zeta.
    \label{eq:syn-lambda-correction}
\end{equation}
Здесь $\mathcal B_\lambda$ --- коэффициент-функция локальной чувствительности витковой дальности к~параметру $\zeta$. На~исследованной области такая коррекция уменьшила RMSE витковой дальности с~$7.31\times10^{-2}$ до~$1.66\times10^{-2}$. Коррекция построена по~локальной чувствительности в~окрестности $\zeta=0$ и~не~является глобальным описанием деформации при произвольных больших $|\zeta|$.

\noindent\textit{$R$-преобразование III~типа.} Преобразование предназначено для задания наклонения $i$ и~долготы восходящего узла $\Omega$. При фиксированном начальном фазовом векторе используется базовая матрица $R_i(j)$, параметризованная управляющей величиной $j$, а~её ориентация задаётся матрицей $Q_\Omega$ поворота вокруг оси $Oz$ на~угол $\Omega$:
\begin{equation}
    R_i(j)=
    \begin{pmatrix}
        1&0&0\\
        0&(1+j^2)^{-1}&-j(1+j^2)^{-1}\\
        0&j(1+j^2)^{-1}&(1+j^2)^{-1}
    \end{pmatrix},
    \qquad
    R_{i\Omega}=Q_\Omega R_iQ_\Omega^{\mathsf T},
\end{equation}
а~управляющий параметр определяется формулой
\begin{equation}
    j=-\frac{i}{\mathcal A^{(i)}(\kappa,\Omega)}.
    \label{eq:syn-r-type3-control}
\end{equation}
Коэффициент-функция $\mathcal A^{(i)}=\mathcal A_0^{(i)}(\kappa)+\mathcal A_1^{(i)}(\kappa)\cos2\Omega$ описывает локальную чувствительность наклонения к~параметру $j$. При $i=0$ полагается $j=0$, а~долгота восходящего узла вырождена. При $\kappa\to1$ функция $\mathcal A^{(i)}$ становится малой, что соответствует вырождению пространственного эффекта для почти совпадающих круговых орбит. В~исследованной области RMSE задания $i$ и~$\Omega$ составили соответственно $3.01\times10^{-3}$ и~$1.12\times10^{-2}$~рад, а~максимальные ошибки --- $1.22\times10^{-2}$ и~$3.36\times10^{-2}$~рад. Одновременно наблюдались побочные деформации витковой дальности $\lambda$ и~большой полуоси $a$, поэтому преобразование используется как начальное приближение с~последующим уточнением. Примеры действия преобразований II и~III~типов приведены на~рис.~\ref{fig:syn-r-types23}.

Для совместного задания полной геометрии преобразования объединяются в~композицию. По~$\lambda_{\mathrm{corr}}$ и~$\kappa$ сначала вычисляются модельные сопряжённые векторы $\widehat{\mathbf p}_{r0}^{\mathrm{corr}}$ и~$\widehat{\mathbf p}_{v0}^{\mathrm{corr}}$, а~через $R_0$ обозначается матрица преобразования I~типа, согласующая модельный и~реальный начальные фазовые векторы. Затем учитываются эллиптичность и~пространственная ориентация конечной орбиты:
\begin{equation}
\begin{gathered}
    R_\Sigma=R_{i\Omega}(j,\gamma)
              R_{e\omega}(\zeta,\bar\omega_{\mathrm{rel}})R_0,\\
    \mathbf p_{r0}^{\mathrm{init}}=R_\Sigma^{-\mathsf T}
       \widehat{\mathbf p}_{r0}^{\mathrm{corr}},
    \qquad
    \mathbf p_{v0}^{\mathrm{init}}=R_\Sigma^{-\mathsf T}
       \widehat{\mathbf p}_{v0}^{\mathrm{corr}},
\end{gathered}
\label{eq:syn-r-composition}
\end{equation}
где $\bar\omega_{\mathrm{rel}}=\Omega+\omega-L_0$, $\gamma=\Omega-L_0$, а~$L_0$ --- истинная долгота начального радиус-вектора. Композиция не является точным аналитическим решением полной задачи; она формирует геометрически согласованное начальное приближение для последующей численной коррекции. Последовательный эффект трёх типов показан на~рис.~\ref{fig:syn-r-composition}.

\noindent\textbf{В четвёртой главе} конечные формулы и~$R$-преобразования объединены в~алгоритм построения начального приближения для прикладных задач баллистического проектирования. Алгоритм связывает дату старта и~целевые орбитальные параметры с~начальным вектором расширенной системы, пригодным для численного уточнения. Его состояние задаётся вектором управляющих параметров
\begin{equation}
    \mathbf q=(\lambda,\kappa,\zeta,\chi,j,\gamma).
    \label{eq:syn-q}
\end{equation}
Пара $\lambda,\kappa$ выбирает точку на~аппроксимированном модельном многообразии, а~остальные параметры задают последовательность линейных преобразований. Их геометрический смысл представлен в~табл.~\ref{tab:syn-control-parameters}.

Тем самым вместо прямого подбора шести сопряжённых переменных используются параметры, связанные с~геометрией перелёта. При композиции преобразований аргумент перицентра согласуется с~пространственной ориентацией орбиты через относительную долготу перицентра $\bar\omega_{\mathrm{rel}}=\Omega+\omega-L_0$.

Алгоритм использует результаты второй и~третьей глав как единую вычислительную схему:
\begin{enumerate}
    \item по~эфемеридам для заданной даты старта определяются начальный фазовый вектор и~элементы целевой орбиты, после чего выполняется переход к~безразмерной постановке;
    \item по~начальной синодической фазе находятся три ближайшие точки оптимальной дальности $\lambda_k^\star$, $k\in\{-1,0,1\}$;
    \item исключаются кандидаты вне физически допустимой области $T>0$ и~области применимости конечных формул, а~среди оставшихся выбирается вариант, удовлетворяющий ограничениям задачи и~дающий наилучшее значение выбранного критерия;
    \item выбранная точка КЛО корректируется по~формуле~\eqref{eq:syn-lambda-correction}, после чего конечные формулы дают $\widehat T$, $\widehat J$ и~$\widehat{\mathbf z}_0^{\mathrm{pl}}$;
    \item композиция~\eqref{eq:syn-r-composition} переводит модельное решение в~начальный вектор расширенной системы $\mathbf y_0^{\mathrm{init}}$ для эфемеридной задачи;
    \item вектор $\mathbf y_0^{\mathrm{init}}$ вместе с~приближённой продолжительностью $\widehat T$ используется для последующего численного решения двухточечной краевой задачи.
\end{enumerate}
Если допустим только один кандидат, выбор на~третьем шаге однозначен.

Программная реализация обеспечивает воспроизводимость вычислительной схемы, но~не заменяет последующее уточнение траектории в~целевой модели движения и~двигательной установки.

\FloatBarrier
\clearpage
\pdfbookmark[1]{Основные результаты и выводы}{main-results}
\begin{center}
    \textbf{ОСНОВНЫЕ РЕЗУЛЬТАТЫ И ВЫВОДЫ}
\end{center}

\begin{enumerate}
    \item Построено модельное многообразие энергетически оптимальных решений задачи встречи с~идеально регулируемой тягой как регулярная связная ветвь, прослеживаемая дискретным продолжением по~двумерной сетке внешних параметров. Показано, что расслоение многовитковых решений в~эфемеридных координатах переходит в~односвязное модельное многообразие. На~нём выделена кривая локальных оптимумов и~введены точки оптимальной дальности как пересечения этой кривой с~изолиниями фиксированной начальной синодической фазы. Вычислительный барьер интерпретирован как граница устойчивого продолжения выбранной ветви, а~не как граница существования решений.

    \item Получены конечные формулы для продолжительности перелёта, непрерывной фазы, квадратичного функционала и~начальных значений сопряжённых переменных в~основной и~маловитковой областях. Их качество проверено на~тестовой выборке по~RMSE, MAE и~максимальной ошибке, а~совокупное качество начального приближения --- повторным интегрированием и~контролем краевых невязок.

    \item Разработаны линейные $R$-преобразования трёх типов: для изменения начального фазового вектора, задания эксцентриситета и~ориентации линии апсид, а~также задания наклонения и~линии узлов конечной орбиты. Установлены их побочные деформации и~вырожденные случаи; локальная коррекция уменьшила RMSE витковой дальности с~$7.31\times10^{-2}$ до~$1.66\times10^{-2}$.

    \item Предложен алгоритм построения начального приближения, который для заданной даты старта проверяет не~более трёх точек оптимальной дальности, исключает кандидаты вне физически допустимой и~рабочей областей, вычисляет модельный сопряжённый вектор и~преобразует его к~целевой геометрии. Параметры $\mathbf q$ используются как интерпретируемая локальная параметризация при численном уточнении. Алгоритм апробирован для перелётов Земля--Марс и~Земля--Венера. На~сетке из~100 марсианских дат оба сравниваемых метода дали 100\% успешных уточнений; в~рассмотренной реализации среднее время составило $0.636$~с против $1.89$~с. Схема продолжена к~задачам с~дополнительным импульсом скорости и~ПСИ-моделью и~реализована в~комплексе \texttt{ILTT Toolbox}.
\end{enumerate}

Дальнейшее развитие работы связано с~переносом предложенной вычислительной схемы на~более сложные постановки оптимизации межпланетных перелётов, выходящие за~рамки модели идеально регулируемой тяги, и~на~задачи с~более общими граничными условиями.
