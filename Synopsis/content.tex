\synopsisheading{Актуальность темы исследования}{actuality}
Проектирование межпланетных перелётов космических аппаратов с~электрореактивными двигательными установками находится на~стыке небесной механики, оптимального управления и~прикладного проектно-баллистического анализа. Высокий удельный импульс таких установок позволяет реализовывать миссии при ограниченной массе рабочего тела, однако длительное управляемое движение существенно увеличивает трудоёмкость баллистического проектирования. Уже на~ранних этапах анализа миссии требуется многократно оценивать допустимые даты старта, продолжительности перелёта, энергетические характеристики траекторий и~параметры управления.

Для предварительного выбора межпланетных траекторий традиционно используются номограммы, связывающие дату старта, продолжительность перелёта и~энергетические характеристики. В~случае непрерывной тяги такая картина имеет дополнительную особенность: решения двухточечной краевой задачи расслаиваются по~числу витков. Поэтому необходимо выбрать не~только окно старта, но~и~семейство траекторий, а~затем сформировать согласованное с~ним начальное приближение для непрямого метода оптимизации. Непосредственное решение задачи с~нуля для каждого набора проектных параметров требует значительных вычислительных затрат и~может приводить к~переходу на~другую ветвь решений.

Теоретической основой непрямой оптимизации служит принцип максимума Л.С.~Понтрягина. Его применение к~задаче перелёта с~непрерывной тягой приводит к~расширенной системе уравнений и~двухточечной краевой задаче, чувствительной к~начальным значениям сопряжённых переменных. Методы продолжения позволяют прослеживать отдельные ветви решений, но~сами по~себе не~дают компактного представления большого массива рассчитанных траекторий, пригодного для быстрого проектного применения.

Исследование движения с~малой тягой имеет развитую отечественную традицию, связанную с~работами Д.Е.~Охоцимского, Т.М.~Энеева, Г.Л.~Гродзовского, Ю.Н.~Иванова, В.В.~Токарева, В.Н.~Лебедева, В.В.~Белецкого, В.А.~Егорова и~В.А.~Ершова. Современные методы оптимизации межпланетных перелётов с~электрореактивной тягой представлены, в~частности, работами В.Г.~Петухова, М.С.~Константинова и~их соавторов. Полученные в~этих исследованиях аналитические, усреднённые и~численные результаты подтверждают ценность конечных зависимостей и~методов продолжения, но~обычно относятся к~специальным режимам движения или требуют последовательного численного решения большого числа краевых задач.

Для межпланетных перелётов с~малым числом витков, существенным изменением радиуса орбиты и~непериодическим управлением универсальные аналитические решения отсутствуют. Перспективным является промежуточное численно-аналитическое представление, которое сохраняет структуру множества решений, допускает интерпретацию через компактные конечные формулы и~содержит начальные значения сопряжённых переменных. Современные методы символьной регрессии дают инструмент получения таких формул по~результатам массового численного расчёта, однако требуют предварительного механического анализа, выбора параметризации и~проверки поведения выражений на~всей рабочей области.

В~диссертации в~качестве регулярной модельной постановки рассматривается энергетически оптимальная задача встречи с~идеально регулируемой непрерывной тягой. Она сохраняет основные трудности непрямой оптимизации и~одновременно позволяет отделить структуру решений от~календарных и~эфемеридных особенностей конкретной миссии. Построенное для этой задачи модельное многообразие используется как связующее звено между массовым расчётом траекторий, конечными формулами и~начальным приближением для прикладной задачи встречи. Поэтому разработка численно-аналитического метода, обеспечивающего согласованный выбор семейства решений и~построение начального приближения, является актуальной задачей динамики космического полёта и~баллистического проектирования.

\synopsisheading{Цель работы}{aim}
Целью диссертационной работы является разработка и~апробация численно-аналитического метода построения начального приближения, согласованного с~выбранным семейством траекторий в~расслоении по~числу витков, для энергетически оптимальных межпланетных перелётов с~идеально регулируемой тягой на~основе модельного многообразия решений задачи встречи.

Для достижения поставленной цели решены следующие \textbf{задачи}:
\begin{enumerate}[beginpenalty=10000]
    \item разработана методика построения, исследования и~аппроксимации модельного многообразия решений задачи встречи с~идеально регулируемой тягой, позволяющая описывать расслоение по~числу витков;
    \item исследовано модельное многообразие решений в~плоской круговой модели движения небесных тел, выделены точки оптимальной дальности и~построены конечные формулы, связывающие параметры компланарного перелёта между круговыми орбитами с~характеристиками траектории и~начальными значениями сопряжённых переменных;
    \item разработаны линейные преобразования начальных значений сопряжённых переменных, позволяющие учитывать изменение начального фазового вектора, эллиптичность и~пространственную ориентацию конечной орбиты при переходе от~плоской круговой модельной постановки к~целевой задаче встречи;
    \item построен и~апробирован алгоритм формирования начального приближения, согласованного с~выбранным семейством траекторий, по~заданной дате старта и~параметрам целевой задачи встречи, включая прикладные задачи Земля--Марс и~Земля--Венера, постановки с~дополнительным импульсом скорости в~начальный момент времени и~последующее продолжение к~постановке с~постоянной скоростью истечения.
\end{enumerate}

\synopsisheading{Объект и предмет исследования}{objectsubject}
Объектом исследования являются семейства энергетически оптимальных решений задач встречи для межпланетных перелётов космического аппарата с~идеально регулируемой непрерывной тягой, рассматриваемые с~точки зрения расслоения по~числу витков. Предмет исследования составляют численно-аналитические методы построения, исследования, аппроксимации и~использования модельного многообразия решений, позволяющие описывать это расслоение и~формировать начальное приближение, согласованное с~выбранным семейством траекторий.

\synopsisheading{Положения, выносимые на защиту}{defpositions}
\begin{enumerate}[beginpenalty=10000]
    \item Методика исследования расслоения решений задачи встречи с~идеально регулируемой тягой по~числу витков, основанная на~построении модельного многообразия решений двухточечной краевой задачи методом дискретного продолжения и~последующей аппроксимации его характеристик; в~рамках методики выделены точки оптимальной дальности, используемые для выбора начального приближения.
    \item Конечные формулы для плоской круговой модели движения небесных тел, позволяющие по~параметрам компланарного перелёта между круговыми орбитами выбирать точку оптимальной дальности и~вычислять продолжительность перелёта, значение квадратичного функционала, начальную синодическую фазу и~начальные значения сопряжённых переменных.
    \item Аппарат линейных преобразований начальных значений сопряжённых переменных при переходе от~плоской круговой модельной постановки к~целевой задаче встречи, учитывающий изменение начального фазового вектора, эллиптичность и~пространственную ориентацию конечной орбиты, а~также конечные формулы для управляющих параметров преобразований и~линейную коррекцию витковой дальности.
    \item Алгоритм выбора начального приближения, согласованного с~выбранным семейством траекторий в~расслоении по~числу витков, и~результаты его апробации в~задачах Земля--Марс и~Земля--Венера, включая учёт дополнительного импульса скорости в~начальный момент времени и~продолжение к~постановке с~постоянной скоростью истечения.
\end{enumerate}

\synopsisheading{Научная новизна}{novelty}
Научная новизна работы состоит в~следующем:
\begin{enumerate}[beginpenalty=10000]
    \item разработана методика применения символьной регрессии для построения интерпретируемых конечных формул, аппроксимирующих характеристики решений задачи встречи с~идеально регулируемой тягой и~пригодных для формирования начальных приближений;
    \item предложено описание расслоения решений, в~котором его структура задаётся пересечениями изолиний начальной синодической фазы с~кривой локальных оптимумов в~точках оптимальной дальности;
    \item на~основе инвариантов, связанных с~первыми интегралами расширенной системы уравнений движения, получены условия на~допустимый вид линейных преобразований начальных значений сопряжённых переменных;
    \item разработан алгоритм построения начального приближения, основанный на~согласованном выборе семейства траекторий, продолжительности перелёта и~начальных значений сопряжённых переменных.
\end{enumerate}

\synopsisheading{Теоретическая и практическая значимость}{significance}
Теоретическая значимость работы определяется исследованием структуры модельного многообразия энергетически оптимальных решений задачи встречи, выделением кривой локальных оптимумов и~точек оптимальной дальности, а~также построением конечных формул для характеристик траекторий и~начальных значений сопряжённых переменных. Разработанные линейные преобразования задают численно-аналитический способ перехода от~плоской круговой модели к~эллиптическим и~пространственным постановкам.

Практическая значимость состоит в~возможности быстрого формирования начальных приближений при массовом проектно-баллистическом анализе межпланетных миссий с~электрореактивными двигательными установками. Аппроксимированное модельное многообразие используется как промежуточное представление между предварительным выбором параметров миссии и~численным уточнением траектории. Подход апробирован на~перелётах Земля--Марс и~Земля--Венера и~реализован в~программном инструменте \texttt{ILTT Toolbox}. Результаты получены и~использовались в~исследованиях, выполнявшихся при поддержке Российского научного фонда, проекты №~19-11-00256 и~№~24-11-00038.

\synopsisheading{Методология и методы исследования}{methods}
В~работе используются методы теоретической механики, небесной механики, оптимального управления и~вычислительной математики: принцип максимума Л.С.~Понтрягина, решение двухточечных краевых задач, дискретное продолжение по~параметрам граничных условий, численное интегрирование расширенной системы, анализ параметрических семейств решений, линейные преобразования начальных значений сопряжённых переменных и~математическое моделирование. Символьная регрессия применяется как инструмент получения конечных формул после выбора параметризации и~анализа структуры модельного многообразия. Качество формул оценивается по~интегральным и~локальным метрикам ошибок, на~независимых контрольных точках и~путём повторного интегрирования расширенной системы.

\synopsisheading{Степень достоверности результатов}{reliability}
Достоверность результатов обеспечивается согласованностью постановки с~необходимыми условиями оптимальности, контролем краевых невязок двухточечной задачи и~устойчивости перехода между соседними точками параметрической сетки. Конечные формулы проверены на~рабочих областях параметров, включая независимые контрольные точки и~области наиболее существенного изменения решений. Для начальных значений сопряжённых переменных выполнена динамическая проверка повторным интегрированием расширенной системы. Свойства линейных преобразований исследованы по~достижению требуемых орбитальных элементов и~по~побочным изменениям витковой дальности и~большой полуоси конечной орбиты. Прикладная проверка включает задачи Земля--Марс и~Земля--Венера и~сравнение способов формирования начального приближения.

\synopsisheading{Апробация результатов работы}{probation}
Основные результаты докладывались на~63-й, 64-й, 65-й и~67-й Всероссийских научных конференциях МФТИ (2020, 2021, 2023 и~2025~гг.); XLVI, XLVIII и~XLIX Академических чтениях по~космонавтике (2022, 2024 и~2025~гг.); молодёжных научных конференциях «Новые горизонты прикладной математики» в~ИПМ им.~М.В.~Келдыша РАН (2024 и~2025~гг.); 75-м Международном астронавтическом конгрессе (Милан, 2024~г.); 23-й Международной конференции «Авиация и~космонавтика» (Москва, 2024~г.); XXIII Научно-технической конференции молодых учёных и~специалистов РКК «Энергия» (Королёв, 2024~г.); 12-м симпозиуме Международной академии астронавтики по~будущему освоению космоса (Турин, 2025~г.).

Результаты обсуждались на~семинарах отдела №~7 «Динамика космических систем» и~отдела №~5 ИПМ им.~М.В.~Келдыша РАН, Баллистического центра ИПМ им.~М.В.~Келдыша РАН, Института космических исследований РАН, Института проблем механики им.~А.Ю.~Ишлинского РАН, а~также на~семинарах Московского авиационного института «Динамические системы и~механика» и~«Механика космического полёта».

\synopsisheading{Публикации}{publications}
По~теме диссертации опубликовано 19 научных работ, в~том числе 6 работ в~изданиях, рекомендованных ВАК РФ, из~них 2 статьи в~изданиях, индексируемых в~международных базах научного цитирования Scopus и~Web of~Science, а~также 13 работ в~изданиях и~материалах научных конференций, индексируемых в~Российском индексе научного цитирования. Получено свидетельство о~государственной регистрации программы для ЭВМ, относящейся к~программной реализации разработанного метода.

\synopsisheading{Личный вклад автора}{contribution}
Основные результаты, выносимые на~защиту, получены автором лично. Автором поставлены и~реализованы вычислительные эксперименты, построено модельное многообразие решений, исследована структура семейств решений, построены и~верифицированы конечные формулы для характеристик траекторий и~начальных значений сопряжённых переменных. Автором разработаны линейные преобразования, исследованы их свойства, построены формулы для управляющих параметров и~проверено качество начальных приближений; выполнена программная реализация вычислительной схемы в~составе \texttt{ILTT Toolbox}. В~совместных работах соавторам принадлежат постановочные, прикладные и~консультационные элементы, связанные с~контекстом проектирования миссий, выбором прикладных постановок и~обсуждением результатов.

\synopsisheading{Соответствие диссертации паспорту специальности}{specialty}
Диссертация соответствует научной специальности 1.1.7 «Теоретическая механика, динамика машин». Вывод расширенной системы уравнений, использование необходимых условий оптимальности и~анализ сопряжённых переменных относятся к~классической механике и~аналитической динамике (направление~1 паспорта специальности). Постановка задачи встречи и~алгоритм выбора начального приближения связаны с~управлением движением механических систем (направление~5). Межпланетные перелёты, движение в~центральном гравитационном поле и~орбитальные элементы соответствуют небесной механике и~астродинамике, а~также динамике летательных аппаратов и~космических конструкций (направления~9 и~10). Построение модельного многообразия, массовые расчёты и~верификация конечных формул относятся к~математическому и~компьютерному моделированию кинематики и~динамики механических систем (направление~14).

\synopsisheading{Объём и структура диссертации}{structure}
Диссертация состоит из~введения, четырёх глав, заключения и~трёх приложений. Полный объём составляет 198~страниц, включая 53~рисунка и~32~таблицы. Список литературы содержит 124~наименования.

В~первой главе формулируется методика построения, исследования и~аппроксимации модельного многообразия решений энергетически оптимальных задач встречи. Во~второй главе исследуется многообразие решений в~плоской круговой модели и~строятся конечные формулы. В~третьей главе разрабатываются линейные преобразования начальных значений сопряжённых переменных для перехода к~эллиптическим и~пространственным постановкам. В~четвёртой главе конечные формулы и~преобразования используются для построения начального приближения в~прикладных задачах баллистического проектирования.
