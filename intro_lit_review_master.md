# Единый мастер-файл рабочего обзора литературы для введения

Это **сводный master-file** по всему `external.bib`.

Принципы файла:

1. у каждого пункта сохраняется **точный `id` из `external.bib`**;
2. файл не является финальным prose для введения;
3. это рабочая матрица для дальнейшего сокращения, отбора и переработки;
4. для части источников, уже вынесенных в отдельные выгрузки 3 и 4, сохранён тот же формат карточек;
5. если `id` в `.bib` неудобный (`__1968`, `__1989` и т.п.), в master-файле он **не исправляется**, чтобы не потерять совместимость с проектом.

## Как использовать файл

- сначала выбрать блок введения;
- затем отфильтровать нужные карточки по полю **«Куда потенциально идёт»**;
- после этого выбрать источники с приоритетом **Высокий** и **Средний**;
- затем уже собирать сокращённый prose для введения;
- источники с пометкой **Резерв** и **Низкий** переносить во введение только при явной необходимости.
