После построения модельного многообразия следующей задачей становится получение компактных конечных формул для его основных характеристик. В данном разделе рассматриваются аппроксимации продолжительности перелёта $T$, начальной синодической фазы $\Phi$ и квадратичного функционала $J$. При этом внимание сосредоточено на гладкой части соответствующих зависимостей; периодические колебания по угловой дальности $\varphi$ на данном этапе сознательно не учитываются.

Для перехода от угловой дальности к более удобной безразмерной характеристике введём витковую дальность
\begin{equation}
	\lambda=\frac{\varphi}{2\pi}.
\end{equation}
В этих переменных продолжительность перелёта аппроксимируется формулой
\begin{equation}
	T=
	\frac{2}{27}\kappa\log\kappa
	+
	\lambda
	\left(
	\kappa-\frac{\sqrt6}{9}\kappa\log\kappa
	\right).
\end{equation}
Эта формула корректно отражает предельный случай
\begin{equation}
	T\big|_{\kappa=1}=\lambda,
\end{equation}
когда начальная и конечная орбиты совпадают. Тем самым аппроксимация для $T$ не только описывает численно построенное многообразие, но и сохраняет правильное поведение в простейшем предельном режиме.

Для начальной синодической фазы используется аппроксимация вида
\begin{equation}
	\Phi=
	A
	\left(
	\lambda\left(e^\kappa+1\right)-\log\kappa
	\right)
	e^{-\kappa}\log\kappa,
	\qquad
	A=0.543328.
\end{equation}
Эта формула была получена как самостоятельная аппроксимация гладкой части фазовой зависимости. Вместе с тем между величинами $\lambda$, $\Phi$ и $T$ существует простая кинематическая связь, поэтому при пренебрежении периодическими колебаниями по $\varphi$ гладкая часть синодической фазы может быть также восстановлена из аппроксимации продолжительности перелёта:
\begin{equation}
	\Phi_{\mathrm{sm}}=
	\lambda-\frac{T}{\kappa^{3/2}}.
\end{equation}
Подставляя сюда найденную формулу для $T$, получаем
\begin{equation}
	\Phi_{\mathrm{sm}}=
	\left(
	1-\frac{1}{\sqrt\kappa}
	+\frac{\sqrt6}{9}\frac{\log\kappa}{\sqrt\kappa}
	\right)\lambda
	-
	\frac{2}{27}\frac{\log\kappa}{\sqrt\kappa}.
\end{equation}
Следовательно, гладкая часть фазовой зависимости в значительной степени уже содержится в аппроксимации продолжительности перелёта. Самостоятельная формула для $\Phi$ в этой ситуации играет роль либо независимой проверки внутренней согласованности полученных аппроксимаций, либо более удобной прямой формулы для практических расчётов.

Для квадратичного функционала используется рационально-тригонометрическая аппроксимация
\begin{equation}
	J=
	\frac{
		\left(
		C_1^J+\dfrac{C_2^J}{\kappa}+\dfrac{C_3^J}{\kappa^2}
		\right)\log\kappa
	}{
		\lambda
		+
		C_4^J
		\left(
		\sin\left(2\pi\lambda+C_5^J-\frac{1}{\lambda}\right)-\lambda
		\right)e^{-\lambda}
	},
\end{equation}
где коэффициенты $C_1^J,\dots,C_5^J$ определяются по результатам символьной регрессии. В отличие от аппроксимаций для $T$ и $\Phi$, здесь осциллирующая структура сохраняется явно, поскольку она оказывает заметное влияние на точность описания функционала.

Практическое использование полученных формул может быть организовано следующим образом. Для заданного значения $\kappa$ и фиксированной даты старта сначала определяется требуемая начальная синодическая фаза. Затем по аппроксимации для $\Phi$ выбирается значение $\lambda$, соответствующее рассматриваемой ветви решений. После этого вычисляются продолжительность перелёта $T$ и значение функционала $J$. Наконец, по формуле из раздела 1.3 значение $J$ переводится в оценку требуемого запаса рабочего тела. Тем самым набор конечных формул позволяет перейти от параметров граничных условий к основным характеристикам энергетически оптимальной траектории без решения полной двухточечной краевой задачи.
