# Содержательные файлы диссертации

Файлы в этой папке получены из канонических DOCX `ВЕРСИЯ_3` скриптом
`tools/docx_to_latex.py`. Повторный запуск скрипта перезаписывает их.

После завершения миграции содержательную редактуру следует выполнять прямо в
LaTeX и не запускать конвертер без осознанной необходимости. Хэши исходных DOCX
и статистика переноса зафиксированы в `migration/conversion_report.json`.
