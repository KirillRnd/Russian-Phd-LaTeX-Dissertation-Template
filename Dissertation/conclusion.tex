\chapter*{Заключение}
\addcontentsline{toc}{chapter}{Заключение}

В диссертационной работе разработан и апробирован метод построения начальных приближений для энергетически оптимальных межпланетных перелётов с идеально регулируемой тягой. Метод основан на построении модельного многообразия решений задачи встречи, его аппроксимации конечными формулами, переносе полученных зависимостей к пространственной и эллиптической постановке и последующем использовании этих зависимостей в задаче баллистического проектирования.

В результате выполненного исследования получены следующие основные результаты.

\begin{enumerate}
	\item Разработана методика построения, исследования и аппроксимации модельного многообразия решений энергетически оптимальных задач встречи. В рамках этой методики энергетически оптимальная задача встречи сведена к двухточечной краевой задаче для расширенной системы, параметры оптимального управления заданы начальными значениями сопряжённых переменных, а модельное многообразие определено как регулярная связная ветвь решений в пространстве внешних параметров. Для построения этого многообразия использовано дискретное продолжение по координатной сетке, а для получения конечных формул сформулирована последовательность численного исследования, выбора параметризации, аппроксимации и проверки качества полученных выражений.
	
	\item Исследовано модельное многообразие энергетически оптимальных решений задачи встречи в плоской круговой модели движения небесных тел и получены конечные формулы для его основных характеристик. Введены кривая локальных оптимумов и точки оптимальной дальности, позволяющие перейти от двумерного множества решений к компактной параметризации аппроксимируемой ветви. Для этой ветви построены конечные формулы для продолжительности перелёта, непрерывной фазы, квадратичного функционала и начального вектора сопряжённых переменных, включая отдельный набор выражений для области малой витковой дальности.
	
	\item Разработан аппарат линейных \(R\)-преобразований начальных значений сопряжённых переменных для перехода от плоской круговой модели к пространственной задаче встречи с учётом эллиптичности орбит. Выделены преобразования при изменении начального фазового вектора, плоские преобразования для задания эксцентриситета и аргумента перицентра конечной орбиты, а также пространственные преобразования для задания наклонения и долготы восходящего узла. Для управляющих параметров этих преобразований получены конечные формулы, построена коррекция витковой дальности при плоском преобразовании и сформирована композиция \(R\)-преобразований, задающая начальный вектор сопряжённых переменных для интегрирования расширенной системы.
	
	\item Разработан алгоритм построения начального приближения для задач баллистического проектирования межпланетных перелётов и выполнена его численная апробация. В качестве управляющих параметров алгоритма использованы витковая дальность, отношение радиусов модельных орбит и параметры \(R\)-преобразований, что позволяет связать аппроксимированное модельное многообразие с орбитальными элементами реальной задачи. На примерах перелётов Земля--Марс и Земля--Венера показано, что получаемые начальные приближения обеспечивают последующее численное уточнение траекторий; также рассмотрены постановки с ненулевой отлётной скоростью, сравнение с продолжением по гравитационному параметру и применение разработанной схемы при проектировании миссии Земля--Венера.
\end{enumerate}

Полученные результаты образуют единую вычислительную схему перехода от модельного многообразия энергетически оптимальных решений к начальному приближению в прикладной задаче баллистического проектирования. Предложенный подход не заменяет последующее численное решение краевой задачи, но позволяет формировать физически осмысленные начальные приближения без предварительного построения полной сетки оптимальных траекторий для каждой новой постановки. Метод реализован в виде программного инструментария ILTT Toolbox.

Дальнейшее развитие работы может быть связано с расширением области применимости конечных формул, уточнением аппроксимаций в области малой витковой дальности, развитием \(R\)-преобразований для более сложных классов граничных условий и переносом предложенной схемы на модели движения и тяги, более близкие к прикладным задачам проектирования межпланетных миссий.
