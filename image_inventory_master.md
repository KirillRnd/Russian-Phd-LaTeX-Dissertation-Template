# Мастер-файл по изображениям диссертации и презентации

Это рабочий инвентаризационный файл для всех картинок, связанных с ВКР, презентацией и присланными скриншотами.

Файл устроен как **рабочий каталог**, а не как финальный список иллюстраций для публикации.

Для каждой единицы стараюсь фиксировать: 

1. имя файла; 2. формальное описание (alt-текст); 3. контекстное описание; 4. место, где изображение должно стоять.



## Важная оговорка

- где исходное имя файла не было видно, я придумал рабочее имя;

- где сопоставление со скриншотами очевидно, оно отмечено как `high`/`medium`;

- где сопоставление предположительное, это прямо отмечено словами `вероятно`, `низкая уверенность` или `invented`.
