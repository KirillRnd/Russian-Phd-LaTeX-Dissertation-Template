# Миграция диссертации Корнеевой А. Д. в LaTeX

## Канонический источник

В качестве содержательного источника используются только восемь документов из
`ОРИГИНАЛ/13.04 ДИССЕР/ВЕРСИЯ_3`. Вложенные побайтные дубли удалены. Остальные
DOCX из `ОРИГИНАЛ` не участвуют в активном графе диссертации.

## Воспроизводимость

1. `tools/docx_inventory.py` формирует `docx_inventory.json` и
   `docx_inventory.md`.
2. `tools/docx_to_latex.py` переносит семь содержательных документов в
   `Dissertation/korneeva`, извлекает изображения и строит
   `biblio/korneeva.bib`.
3. `tools/latex_audit.py` проверяет активный граф включений и структуру LaTeX.
4. `migration/build_report.json` и `migration/VISUAL_AUDIT.md` фиксируют
   машинную и визуальную проверку итогового PDF.

Сгенерированные `.tex`-файлы сохраняют формулировки исходников. Нормализованы
структура заголовков, специальные символы, сноски, таблицы, изображения и
блоки программного вывода. Ручная литературная редактура в рамках миграции не
выполнялась.

## Результат переноса

- три блока введения: контекст, историография и источниковедение;
- три главы;
- 947 используемых сносок;
- 29 многостраничных таблиц;
- 6 извлечённых иллюстраций;
- техническое приложение;
- 492 библиографические записи.

Полные описания библиографии сохранены дословно в поле `title` записей
BibLaTeX. Это намеренное промежуточное представление: оно не домысливает авторов,
редакторов и типы изданий, если исходная строка не содержит однозначной
структуры. Ссылки в исходных сносках также сохранены дословно; автоматическая
замена 947 сносок на ключи `\\cite` не выполнялась из-за риска неверного
сопоставления сокращённых ссылок.

## Активная структура

Основной файл `dissertation.tex` подключает только новое содержание из
`Dissertation/korneeva`. Старые главы о межпланетных перелётах не входят в граф
сборки и не влияют на итоговый PDF.

Итоговая проверенная сборка содержит 447 страниц. В журнале нет ошибок LaTeX,
неопределённых ссылок, неопределённых цитирований и пропущенных глифов.
