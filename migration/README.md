# Архив однократной миграции из DOCX

Каталог хранит отчёты и графы, полученные при завершённом переносе диссертации
из DOCX в LaTeX/BibLaTeX. Это исторические материалы, а не активная часть
сборки.

Повторный импорт намеренно не поддерживается: импортёры удалены, команд их
запуска в проекте нет. Канонические редактируемые источники:

- `Dissertation/korneeva/*.tex` — текст диссертации;
- `biblio/korneeva.bib` — основной каталог записей;
- `biblio/korneeva_full.bib` — полная база, подключённая к диссертации.

Файлы `conversion_report.json`, `citation_graph.json`,
`citation_graph_report.json`, `citation_mentions.csv`, `docx_inventory.*` и
прочие материалы этой папки оставлены только для проверки происхождения уже
перенесённого текста. Они не должны генерировать или перезаписывать `.tex` и
`.bib`.
