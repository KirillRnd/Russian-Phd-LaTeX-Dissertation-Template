# Рабочая политика библиографии

## Единственный источник данных

Каноническая база проекта — `biblio/korneeva_full.bib`. Импорт из DOCX в
цепочке отсутствует. Поле `annotation` хранит исходную запись только для
сверки и не участвует в печатном описании.

## Типы записей

| Материал | Тип BibLaTeX | Ключевые поля |
|---|---|---|
| монография с автором | `book` | `author`, `title`, `date`, `location`, `publisher` |
| сборник или издание под редакцией | `collection` | `editor`, `title`, `date`, `location`, `publisher` |
| статья в журнале | `article` | `author`, `title`, `journaltitle`, `date`, `volume`/`number`, `pages`; для электронной статьи без пагинации — `eid`, `doi` или точный `url` вместо `pages` |
| глава в сборнике | `incollection` | `author`, `title`, `booktitle`, `editor`, `date`, `pages` |
| доклад в трудах конференции | `inproceedings` | `author`, `title`, `booktitle`, `editor`, `date`, `pages` |
| самостоятельная веб-страница, словарная статья, база, ПО | `online` | `title`, `url`, `urldate`; автор/организация и дата — если указаны ресурсом |
| архивная единица хранения | `misc` | `title`, `institution`/`organization`, шифр в структурных полях или `note` |
| диссертация | `thesis` | `author`, `title`, `type`, `institution`, `date`, `location` |

Нельзя записывать журнал целиком в `booktitle`, дату обращения — в `date`,
а обозначения `С.`, `P.`, `Vol.` — внутрь числовых полей.

Дата создания архивной единицы приводится, когда она установлена. Само по
себе её отсутствие не делает ссылку неполной, если архив, коллекция, шифр и
листы позволяют однозначно найти объект.

## Язык и имена

Каждая запись имеет явный `langid`. В основной сборке он позволяет корректно
переключать переносы и локализацию; каталанский, испанский, французский,
немецкий, итальянский и латинский не сводятся к английскому. Язык определяется
по языку заглавия описываемого издания, а не по языку диссертации или месту
издания. Технический HTML-предпросмотр фиксирует русский язык самого
библиографического описания: это обход ограничения TeX4ht при переключении
OpenType-шрифтов внутри одной записи, но `langid` из данных не удаляет.

Имена задаются как `Фамилия, Имя/инициалы`; несколько лиц разделяются словом
`and`. Роли не прячутся в `note`: применяются `author`, `editor`, `translator`
и другие поддерживаемые списки имён. Корпоративный автор заключается в
дополнительную пару фигурных скобок.

## Электронные ресурсы

- `url` содержит только адрес, `doi` — только идентификатор без
  `https://doi.org/`.
- `urldate` всегда имеет ISO-формат `YYYY-MM-DD` и означает дату обращения.
- `date` означает дату публикации или обновления страницы. Если ресурс её не
  сообщает, дата не выдумывается; стиль использует локализованное обозначение
  отсутствующей даты.
- Статья электронного журнала остаётся `article`, а не `online`: URL и дата
  обращения дополняют обычные сведения о журнале.
- `organization` хранит название сайта или ответственной организации у
  самостоятельной веб-страницы.

## Проверка и сборка

Нормализация принятых решений выполняется идемпотентно:

```powershell
python tools/normalize_bibliography.py --write
```

Аудит пишет читаемый отчёт `output/bibliography/audit.md` и с флагом ниже
останавливает сборку, если хотя бы одна запись не готова:

```powershell
python tools/audit_bibliography.py --fail-on-not-ready
```

Единственная отдельная сборка библиографии:

```powershell
python tools/build_bibliography.py
```

Результат — `output/bibliography/bibliography-preview.html`. PDF на этом этапе
не создаётся. После сборки автоматически проверяются полнота списка, Unicode,
диакритика и несколько русских, латинографических и сетевых регрессионных
случаев. Диагностические пометы `review` сохраняются отдельно и не означают,
что отсутствующую в самом издании факультативную роль следует выдумывать.
